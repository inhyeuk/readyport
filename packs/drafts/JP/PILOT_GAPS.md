# JP 시범 5곳 — 출처를 못 찾은 칸·약한 근거 기록 (2026-10-09)

`attractions.json`에 넣지 않았거나(빈 칸), 넣었지만 근거가 약한 칸을 모았다. 사장님이 "정보량을 어디까지 기대할 수 있는지" 판단하는 자료다.
표기: **빠짐** = 출처가 없어 넣지 않음 · **약함** = 넣었지만 근거가 약해 사람 확인 필요 · **판단** = 편집 판단이 들어간 칸.

## 공통

| 칸 | 상태 | 내용·시도한 것 |
|---|---|---|
| 여는 시간·요금 숫자 | 빠짐(의도) | D4-A에 따라 넣지 않음. `volatile: null` |
| `regular_closed`의 근거 | 판단 | "쉬는 요일" 칸은 공식 문구가 있을 때만 `none`, 없으면 `unknown`(화면에 안 그림) |
| `booking` | 빠짐 | 센소지·후시미 이나리·도톤보리는 예약에 관한 공식 문구를 못 찾아 키 자체를 넣지 않음 |
| 숫자가 들어간 문장 | 판단 | D4는 "시간·요금 숫자"만 금지로 읽었다. 그래서 관람 소요(2시간·1시간), 휴관 날짜(12/28~1/1), 행사 날짜(7/9~10 등), 연도·높이·개수는 넣었다. 다르게 보시면 `visit_note_ko`와 팁 2개를 빼면 된다 |
| `rank.designations[].kind` 값 | 판단 | `packs/schema/attractions.enums.json`이 아직 없어서 `jp_special_historic_site`·`jp_place_of_scenic_beauty`를 임시로 정함. 스키마 쪽과 맞춰야 함 |
| 부분 지정(경내 건물 하나만 지정) | 판단 | 절·신사 전체가 아니라 문·본전 하나가 지정된 경우는 `rank.designations`에 넣지 않고 CSV `부분 지정(참고)` 열에만 적음. D11 "공식 지정"에 부분 지정을 넣을지 결정 필요 |
| Wikidata P1435(지정) | 약함 | 오사카성·후시미 이나리의 P1435 참조는 P143(가져옴)·P4275(DB 번호)뿐이라 스펙 §5.1 "유효 참조"가 아님. 지정 사실은 문화청 DB를 직접 인용함 |
| 근거 스냅샷 위치 | 판단 | 지시대로 `packs/sources_cache/JP/`에 **발췌만** 저장했다. 스펙 §5.3은 "저장소 밖(`~/.readyport/evidence`), 인용 원문은 저장소에 넣지 않음"이다. 저장소(inhyeuk/readyport)가 공개라 push 전에 위치를 정해야 함 |
| copycheck | 빠짐 | 한국어 위키백과·나무위키·관광청 한국어 페이지 비교본을 모으지 않음(도구 미완성). JNTO 한국어 페이지(후시미)는 읽었지만 문장을 가져오지 않음 |
| 사진 | 빠짐(의도) | D3-A. `photo_link`에 Wikidata P18의 Commons 파일 링크만 둠 |
