레디포트 개인정보 처리방침

시행일: 2026년 9월 29일 · 개정: 2026년 9월 30일(YouTube 여행 영상) · 앱: 레디포트(com.readyport)

레디포트는 해외여행 입국 서류 준비를 돕는 앱입니다. 여권 정보 같은 개인정보는 운영자 서버로 보내지 않고, 이용자의 기기 안에만 암호화해 보관합니다. 레디포트는 정부 기관과 제휴하지 않은 민간 앱입니다.

1. 기기 안에만 보관하는 정보

여권 정보(이름·여권 번호·생년월일·국적·성별·만료일), 함께 가는 가족의 여권 정보, 예약 서류, 입국 QR 사진, 여행 나라와 날짜, 가는 곳 주소, 준비물 체크, 쇼핑 목록, 앱 설정.

여권·예약 서류는 Android 키 저장소의 키로 암호화(AES-256-GCM)하고, 휴대폰 잠금(지문·PIN)을 확인해야 열립니다. 클라우드 백업과 기기 이전에서 제외되며, 운영자는 이 정보를 볼 수 없습니다.

여권·서류 사진은 기기 안에서 글자만 읽은 뒤 바로 지웁니다. 입국 QR처럼 이용자가 보관을 고른 사진만 암호화해 보관합니다.

여행이 끝나면 여권 정보를 지우도록 안내합니다('여행 종료 후 자동 파기', 기본 켬). 앱의 '지갑 › 모두 지우기'나 앱 삭제로 언제든 모두 지워집니다.

2. 이용자가 직접 정부 사이트에 입력·제출하는 정보

'자동 입력'을 쓰면, 이용자가 한국어·영어·현지어로 확인한 값을 앱 안의 브라우저로 연 각국 정부 공식 사이트의 입력 칸에 넣습니다. 제출 버튼은 이용자가 직접 누릅니다. 이 정보는 해당 정부 사이트로 전송되며, 그 처리는 각 정부 사이트의 방침을 따릅니다. 레디포트 운영자는 이 정보를 받지 않습니다.

3. 운영자 서버로 보내는 정보 (개인을 알아볼 수 없는 정보만)

항목내용목적보관

이름·여권 번호·연락처·위치·여행 날짜는 보내지 않습니다.

4. 앱에 들어 있는 외부 서비스

  • Google Firebase(Hosting·Remote Config·Cloud Firestore·Cloud Messaging·App Check·Installations): 안내 자료 배포, 알림, 남용 방지. 앱 버전·기기 종류·국가 코드·설치 ID 같은 기술 정보를 수집할 수 있습니다. Firebase 개인정보 보호
  • Google ML Kit(글자 인식): 사진은 기기 안에서 처리합니다. 진단용 기기·성능 정보와 설치별 식별자를 Google에 보낼 수 있습니다. ML Kit 데이터 공개
  • YouTube API 서비스(나라별 여행 영상 목록): 운영자 서버 작업이 YouTube Data API로 공개 영상의 제목·채널·조회수·구독자 수·게시일·썸네일 주소를 받아 저장하고, 30일 안에 새로 받습니다. 이용자 정보는 YouTube에 보내지 않습니다. 앱에서 영상 목록을 열면 썸네일 이미지를 YouTube 서버(i.ytimg.com)에서 바로 불러오므로 기기의 IP 주소 같은 기술 정보가 Google에 전달될 수 있고, 영상을 누르면 YouTube 앱이나 브라우저가 열립니다. 영상 목록을 쓰면 YouTube 서비스 약관에 동의하는 것으로 봅니다. Google 개인정보처리방침
  • 광고·분석 SDK는 넣지 않았습니다.

5. 제3자 제공과 국외 이전

운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 3절의 정보는 개인을 알아볼 수 없는 정보이며, Google Cloud(Firebase)의 미국 소재 서버에 저장됩니다(인터넷으로 전송, 위 보관 기간 동안).

6. 아동

만 14세 미만 자녀의 여권 정보는 보호자가 '가족 모드'로 보호자 기기에 등록합니다. 자녀 폰 모드는 입국 QR과 도움 기능만 보여 주며, 자녀 기기에서 서버로 보내는 개인정보는 없습니다.

7. 이용자의 권리

앱의 개인정보는 모두 이용자 기기에 있으므로 이용자가 직접 열람·수정·삭제할 수 있습니다. 3절의 정보는 개인과 연결되지 않아 개별로 찾아 지우기 어렵지만, 보관 기간이 지나면 자동으로 지워집니다.
