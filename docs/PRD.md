# 레디포트 PRD (제품 요구사항)

> 원본: `docs/source/ReadyPort_ClaudeCode_Prompt.md` (2026-09-28 기준). 장 번호는 원본과 같다.
> `[재확인]` = 조사 시점 사실이지만 바뀔 수 있음, 구현 전 공식 출처로 재확인. `[확인 필요]` = 미확정, 추측 금지·운영자에게 질문.
> 부록 B 이용 시나리오는 수용 테스트 기준으로 쓴다.
> 2026-10-01 갱신: 앱 구조 개편(0.2.0~0.3.1 — 탭 4개·나라 화면·비자 온라인 신청·YouTube 영상)과 디자인 개편(`docs/design/DESIGN_SPEC_2026-10-01.md`), 운영자 결정(`docs/design/OWNER_DECISIONS.md` 마지막 절)을 반영했다.

## 1. 제품 개요

| 항목 | 내용 |
|---|---|
| 앱 이름 | 레디포트 (ReadyPort) |
| 플랫폼 | Android (Kotlin, Jetpack Compose) |
| 가격 | 무료. 광고 없음. 수익은 수수료 링크(제휴 프로그램 링크, 11.2절)로만 |
| 한 줄 정의 | 해외여행 준비부터 귀국까지 함께하는 '여행 필수품' 앱. 입국 사전신고를 앱이 대신 채워 주고, 사용자는 확인과 최종 제출만 한다 |
| 핵심 대상 | 해외여행 경험이 없는 중학생, 중년 이상. 누구나 설명 없이 쓸 수 있어야 한다 |
| 핵심 약속 | ① 여권 등 개인정보는 폰 밖으로 나가지 않는다 ② 인터넷이 없어도 핵심 기능이 동작한다 ③ 공식 출처와 최종 확인일을 항상 보여준다 |
| 서버 | Firebase 무료 요금제(Spark)만 사용. 서버 로직 없음 |
| 운영 | 정책·양식·콘텐츠 변경 감지와 반영은 ARIA(운영자 PC의 자율 에이전트)가 담당 |

### 1.1 서비스 원칙 (전문가 검토로 확정)

1. 한 화면에는 할 일 하나. 다음에 누를 버튼이 항상 분명해야 한다.
2. 쉬운 말. 중학교 1학년 수준 어휘를 쓰고, 전문 용어에는 풀이를 붙인다.
3. 앱이 채우고 사람은 확인한다. 사용자는 승인과 최종 제출만 한다.
4. 인터넷이 없어도 동작한다. 찜한 여행지와 도움 탭은 항상 오프라인.
5. 현지어는 '읽는 용'이 아니라 '보여주고 들려주는 용'으로 크게 표시한다.
6. 모든 정책 정보에 공식 출처와 최종 확인일을 붙인다.
7. 개인정보는 기기 안에만 둔다.

## 2. 서비스 범위 — 국가·양식

### 2.1 사전신고 유형별 지원 수준

| 유형 | 대상 (2026-09 기준 `[재확인]`) | 지원 수준 | 단계 |
|---|---|---|---|
| 무료 전자 입국카드 (웹) | 태국 TDAC, 말레이시아 MDAC, 싱가포르 SG Arrival Card, 인도네시아 All Indonesia(입국·세관·검역 통합), 일본 Visit Japan Web | 자동 입력 + 사용자 최종 제출 | **MVP** |
| 유료 전자여행허가 (웹 경로 있음) | 캐나다 eTA, 뉴질랜드 NZeTA, 영국 ETA 웹 신청 | 자동 입력. 결제·얼굴 사진·배경 질문은 사용자 | 2차 |
| 공식 앱 전용 (칩 판독·실시간 얼굴 인증) | 호주 ETA, 영국 ETA 앱, 미국 ESTA | 자동화하지 않음. 준비물 체크리스트, 공식 앱 연결, 값 복사 버튼만 | 2차 |
| 시행 예정 | EU ETIAS | 감시만. 시행 확정 시 추가 | 관망 |

참고 사실 `[재확인]`:
- 태국 TDAC는 도착 72시간 이내에만 제출 가능, 무료.
- 싱가포르 SG Arrival Card는 도착 3일 이내 제출.
- 미국 CBP는 ESTA 웹사이트 신규 신청을 폐지하고 모바일 앱으로 단일화하는 안을 제시했다(2025-12). 대리 신청 시에도 신청자 본인 얼굴 사진이 필요하다.
- 영국 ETA는 2026-04-08부터 £20. 대리 신청 가능하나 "다른 사이트·앱을 통해도 결정이 빨라지지 않는다"고 공식 안내.
- EU ETIAS는 2026년 말 목표가 공식 사이트에서 삭제되었고 2027년 연기 가능성이 보도됨.
- 2026년 봄 인도·베트남도 디지털 입국카드를 도입. 양식 수는 계속 늘어나는 추세.

### 2.2 절대 자동화하지 않는 것 (사람 확인 지점)

- 캡차(보안 문자). **우회 시도 금지**.
- 이메일·문자 OTP
- 셀피·실시간 얼굴 인증
- 결제
- 서약, 세관·건강·범죄 이력 질문. 앱이 추정하거나 기본값으로 채우지 않는다. 그림 + 예/아니오로 사용자가 직접 답하게 한다.
- 최종 제출 버튼

## 3. 대상 사용자와 사용 모드

### 3.1 페르소나

| 페르소나 | 특징 | 설계 반영 |
|---|---|---|
| 58세 부부, 첫 해외여행 | 무엇을 모르는지 모름, 작은 글씨·스와이프 어려움 | 쉬운 모드, '지금 할 일' 1개, 음성 안내 |
| 중학생 자녀를 둔 4인 가족 | 보호자가 서류를 한꺼번에 관리 | 가족 모드 |
| 중학생 (첫 해외여행) | '승인', '입국신고서' 같은 말을 모름 | 쉬운 말 사전, 버튼 문구 |
| 저시력 70대 | 큰 글씨, 높은 대비 필요 | 글자 확대 대응, 명도 대비 |
| 배낭여행 경험자 | 빠르게 쓰고 싶음 | 기본 모드 |

### 3.2 쉬운 모드
- 첫 실행 때 "해외여행이 처음이세요?"라고 묻고, 예라고 하면 기본으로 켠다. 설정에서 끄고 켤 수 있다.
- 글자 18~28sp, 버튼 높이 56dp 이상(지금 64dp), 누르는 요소 최소 56dp, 한 화면 한 가지 주요 동작.
- **28sp 예외 (D19, 운영자 승인 2026-10-01)**: 현지인에게 보여 주는 글자(현지어 전체 화면·기사님께 보여주기·도움 선택 문장), 히어로 이름, 큰 숫자는 28sp를 넘어도 된다. 크기: displayLarge 56 · displayMedium 36 · displaySmall 32 · stat 34 · localLarge 56 · localMedium 32 (sp). 그 밖의 글자는 18~28sp 그대로.
- 하단 탭 라벨은 18sp 아래로 줄이지 않는다. 자리가 모자라면 두 줄로 쓴다.
- 화면은 항상 1열. 홈의 여행 준비 카드 넷(출국하는 날·꼭 챙길 물건·귀국 전 확인·내 정보)은 한 줄씩 접어 두고 그 자리에서 펼친다(운영자 결정 8번).
- 스와이프 제스처 금지. 모든 동작은 버튼으로.
- 모든 화면에 '처음으로' 버튼.
- 음성 안내: Android TextToSpeech(기기 내장) 사용.

### 3.3 가족 모드
- 보호자 폰이 대표로 가족 전체의 여권·프로필·QR을 관리한다.
- 자녀 폰에는 자기 QR과 도움 탭만 단순하게 보여준다.
- 자녀 QR을 자녀 폰으로 옮길 때는 서버를 거치지 않고 기기끼리 직접 공유(QR 스캔 또는 시스템 공유)한다.
- 동행자 등록 시 "본인 또는 보호자가 동의했나요?" 확인 문구를 표시한다.

### 3.4 쉬운 말 사전 (UI 문구 규칙)

| 원래 용어 | 앱 문구 |
|---|---|
| 전자여행허가(ETA) | 미리 받는 입국 허락 |
| 입국신고서 | 도착 전에 내는 입국 카드 |
| 세관 | 가방 속 물건을 확인하는 곳 |
| 체크인 | 비행기 표 받고 짐 맡기기 |
| 승인 | "맞아요, 입력해 주세요" |

`app/src/main/res/values/strings.xml`에 원래 용어를 쓰지 말고, 쉬운 말 문구를 기본으로 한다. 전문 용어가 꼭 필요하면 괄호로 병기한다.

## 4. 정보 구조 (IA)

### 4.1 하단 탭 4개 (0.2.0, 2026-09-29 운영자 요청으로 개편)

예전 5탭(오늘·준비·여행지·지갑·도움, 부록 A 2회차)을 아래 4탭으로 바꿨다. 나라를 먼저 고르고, 그 나라에서 입국·여행·쇼핑을 모두 보게 한다.

| 탭 | 역할 | 주요 화면 |
|---|---|---|
| 홈 | 첫 화면. 나라 고르기 + 여행 기본 정보 | 사진 머리글(가치 문장 + 신뢰 표시), 내 여행 요약(여행이 있을 때), **나라 사진 카드 → 나라 화면**, 급할 때는 도움, 여행 준비 기본 정보(출국하는 날 순서·꼭 챙길 물건·귀국 전 확인·내 정보) — 5.12 |
| 내 여행 | 여행 단계에 따라 바뀌는 할 일 | 여행 단계 표시, 지금 할 일 1개(준비 중: 입국 카드·여권·체크리스트 / 도착: 입국 QR / 여행 중: 숙소로 돌아가기 등 / 귀국: 반입 확인·여권 정보 지우기), **지금 챙길 것(체크리스트 몇 줄)**, 여행 만들기·고치기, **내 여행 목록·여행 체크리스트**(5.16), 여행 준비(입국 카드·꼭 챙길 물건), 입국 때 보여 주기 — 5.1, 5.4 |
| 도움 | 위기 대응 (항상 오프라인) | 현지어 문장 카드, 긴급 번호, 대사관, 이럴 땐 이렇게(여권 분실·아플 때), 어느 나라에서나(영사콜센터) — 5.11 |
| 설정 | 내 정보와 앱 설정 | '내 정보는 이 휴대폰에만 저장돼요' 배너, 내 정보(여권·예약 서류)·같이 가는 사람, 쉬운 모드·자녀 폰 모드, 와이파이에서만 받기, 개인정보 안내·출처와 알림·사진·글꼴 출처·앱 정보 — 5.5, 5.15 |

- **나라 화면**(홈 › 나라 사진 카드, 5.13): 대표 경치 머리글(찜 버튼·최종 확인일·저장 상태) + 세 갈래 전환 `입국·비자 / 여행 정보 / 쇼핑`(누르는 버튼, 스와이프 없음).
  - 입국·비자: 정부 비제휴·제출은 직접 안내 → 비자 카드 → (비자가 필요한 나라만) 비자 온라인 신청 → 입국 카드 → 들어갈 때 → 여행 계획 만들기.
  - 여행 정보: 현지에서 쓰는 도구(현지어와 긴급 번호 · 이동하기 · 여행 영상 · 오프라인 지도) → 전기 → 돈·안전 → 지도도 저장해 두세요. 여행 영상은 YouTube 영상 목록(5.14).
  - 쇼핑: 한국인이 많이 사는 물건 미리보기 → 쇼핑 리스트(5.8), 귀국 전 확인 한 줄 요약.
- 하위 화면(나라·영상·쇼핑·꼭 챙길 물건·내 정보 등)은 제목 왼쪽에 '이전 화면으로' 버튼이 있다(0.3.1). 탭 첫 화면에는 없다.
- 자녀 폰 모드(3.3): 하단 탭이 `입국 QR · 도움` 두 개가 된다.
- 지금 없는 화면: 요즘 인기 여행지(11.1, 순위 데이터 C3·C4 연결 뒤 켬 — 문구 15개는 보존, 운영자 결정 16번), 찜한 여행지 목록(찜은 나라 화면 머리글의 하트 → 와이파이에서 최신 팩 받기·정책 변경 알림 구독), 알림 설정·오류 제보·여행사 소개(2차).
- 도움 탭 아이콘·라벨은 다른 탭과 구분되는 따뜻한 색(#A8431A)으로 항상 표시한다.

### 4.2 여행 단계 (8단계) — '내 여행' 탭이 단계에 맞춰 자동 전환

| 단계 | 시점 | 앱이 알아서 하는 일 | 사용자가 하는 일 |
|---|---|---|---|
| ① 꿈꾸기 | 언제든 | 찜한 여행지를 Wi-Fi에서 자동 저장 | 찜하기 |
| ② 여행 만들기 | D-60 전후 | 필요한 서류 판정, 준비 일정 자동 생성 | 목적지·날짜·동행자 입력 |
| ③ 준비 | D-30~D-1 | 여권 유효기간 점검, 제출 가능일 알림, 꼭 챙길 물건 목록, 교통 앱 설치·가입 안내 | 여권·예약 서류 촬영, 앱 설치 |
| ④ 사전 신고 | 제출 가능일 | 3개 국어 확인 화면 준비, 공식 사이트 자동 입력 | 확인, 보안 문자, 최종 제출 |
| ⑤ 출국 | 당일 | 공항 가는 법, 체크인·보안검색 순서 카드 | 순서대로 따라가기 |
| ⑥ 도착 | 현지 도착 | 시간대 변경 감지 → 도착 모드: 입국심사 → 짐 → 유심 → 환전 → 숙소 이동 순서 카드, 입국 QR 즉시 표시. **여행에 내리는 공항을 골라 두면(또는 팩 공항이 하나면) 입국심사·짐 대신 그 공항의 순서(팩 `airports` — 위치·입국 카드 확인 줄·출처)를 보이고 유심·환전·숙소가 번호를 이어 간다**(2026-10-03) | QR 보여주기 |
| ⑦ 여행 중 | 매일 | 다음 일정, 이동 앱 연결, 현지어 카드, 오프라인 가이드 | '여기로 가기' |
| ⑧ 귀국·정리 | 귀국 후 | 한국 입국 안내, 쇼핑 목록 반입 확인, 여권 정보 파기 예고(미루기 가능), 경비 정리 | 파기 확인 |

- 도착 감지는 위치 권한 없이 `ACTION_TIMEZONE_CHANGED` + 여행 일정으로 판단한다.

- ⑤ 대한민국 대사관(이름·주소·대표/근무시간 외 번호), ⑥ 이럴 땐 이렇게(여권 분실·아플 때 할 일 순서), ⑦ 어느 나라에서나(영사콜센터).
- 문장 카드에 '원어민 검수 전' 배지는 보이지 않는다(운영자 결정 2번, 검수 자체는 출시 전 할 일 — 5.2 참고).

### 5.12 홈 (0.2.0)
- 사진 머리글: 앱 이름, "어디로 떠나세요?", 가치 문장 "입국 카드 칸은 앱이 채우고, 제출만 직접 눌러요", 신뢰 표시 `공식 출처만 · 폰에만 저장 · 인터넷 없이도`(누를 수 없는 정보 칩). 1열(쉬운 모드·큰 글자)에서는 신뢰 표시를 나라 사진 목록 아래에 둔다 — 첫 화면에 나라 사진이 보이게(운영자 결정 9번).
- 여행이 있으면 내 여행 요약 카드(나라 사진·출발까지 며칠·날짜·'내 여행 보기').
- 나라 사진 카드: 여행 중인 나라(없으면 첫 나라)는 크게 1장, 나머지는 2열. 카드마다 비자 요약 칩 하나(예: '비자 없이 90일'), 목록 아래 출처 줄. 누르면 나라 화면(5.13).
- '급할 때는 도움' 줄 → 도움 탭.
- 여행 준비 기본 정보: 출국하는 날 순서(공항 사진 카드 + 번호 단계), 꼭 챙길 물건(플러그·전압·보조배터리, 진행), 귀국 전 확인(한 줄 요약 + 펼치기, 운영자 결정 10번), 여권 정보는 한 번만 등록(→ 내 정보). 쉬운 모드에서는 넷 모두 접어 둔다(3.2).

### 5.13 나라 화면 (0.2.0, 비자 온라인 신청 0.2.1)
- 머리글: 대표 경치 사진 + 나라 이름 + 최종 확인일·저장 상태 칩, 뒤로·찜 버튼. 그 아래 `입국·비자 / 여행 정보 / 쇼핑` 전환 버튼(누르면 바뀜, 스와이프 없음).
- **입국·비자**:
  - ① 정부 비제휴 안내 + "마지막 제출은 직접 눌러요"(첫 항목, 8.1).
  - ② 비자 카드(흰 카드): 결론 문장(팩 `visa` 값) + 숫자 타일(머무를 수 있는 날, 입국 카드 비용 등 — 팩 구조 필드에서만) + 출처. 입국 카드 제출 기간 타일은 아직 그리지 않는다(D11, 아래 참고).
  - ③ 입국 카드(양식) 카드: 이름·비용·내는 기간 글 행 + '입력 도와받기'(레시피가 있는 양식 → 5.2) 또는 '입력할 값 준비하기'(레시피 없는 양식 → 값 복사해서 넣기).
  - ④ **비자 온라인 신청**(한국 일반 여권으로 비자가 필요한 나라만 — 지금은 인도네시아 e-VOA): '1단계 입국 신고(All Indonesia, 주 버튼) → 2단계 비자 신청(e-VOA, 보조 버튼)' 순서로 보인다. 신청 순서·요금(IDR 500,000, 환불 불가)·가짜 사이트 경고(빨간 띠)·"앱은 입력 칸만 채워 드려요. 신청 버튼과 결제는 직접 하세요"·출처(주인도네시아 대사관 공지). 입력은 기존 All Indonesia 자동 입력이 돕고, 신청 버튼·결제·캡차는 사람이 한다(ARCHITECTURE '비자 온라인 신청').
  - ④b **공항에 도착하면** (2026-10-03, 운영자: "각 국가별 공항에서 입국 신고하는 위치를 안내"): 입국 카드 카드 다음 카드뉴스 한 장 — 공항 이름 칩(둘 이상일 때, 처음 = 부른 곳이 준 공항 → 이 나라 여행의 내리는 공항 → 팩 첫 공항) → 공항 머리(이름·도시·코드·영어 이름) → 번호 단계(단계마다 kind 아이콘, 공식 안내에 적힌 위치만 위치 칩, 짧은 설명) → 입국 심사(또는 form_check) 단계 안 노란 강조 줄 `TDAC를 내고 받은 접수 확인 메일을…`(입국 카드를 어디서 보여 주는지) → 한국 여권 자동 출입국 심사대 줄(공식 안내가 한국 여권을 콕 집어 밝혔을 때만 ✅/❌, 모르면 숨김) → `공항 안내도 열기 (공식)`(브라우저) → 출처. 팩에 공항이 없으면 카드가 없다.
  - ⑤ 들어갈 때(팩 문장, 뜻 없는 점 불릿) + 출처 → ⑥ '여행 계획 만들기'(이 나라를 미리 골라 둠).
  - 태국 TDAC 제출 기간 문장은 외교부 해외안전여행 원문("입국하는 날을 포함하여 입국 전 3일 이내", 2026-10-01 확인)에 맞춰 팩을 고쳤다(TH 팩 2026.10.01-1, 배포는 main 머지 때).
- **여행 정보**: (여행경보 문장이 있으면 맨 위 빨간 띠) → 현지에서 쓰는 도구 타일 4개(현지어와 긴급 번호 → 도움 탭, 이동하기 → 5.9, 여행 영상 → 5.14, 오프라인 지도 → 아래 지도 카드) → 전기(한국 플러그가 맞는지 결론 + 플러그·전압·주파수) → 돈·안전 → 지도도 저장해 두세요.
- **쇼핑**: 한국인이 많이 사는 물건 3개 미리보기(분류 아이콘·반입 판정·출처) + '쇼핑 리스트 보기'(5.8) → 귀국 전 확인(한 줄 요약 + 펼치기).

### 5.14 여행 영상 (0.3.0, 검색 0.3.1)

### 5.16 내 여행 목록·여행 체크리스트 (2026-10-02 운영자 요청)

- **내리는 공항 (2026-10-03)**: 여행 만들기·고치기에 `내리는 공항`(그 나라 팩 `airports`에 있는 공항 칩 + `아직 몰라요`, 팩에 공항이 없으면 칸 없음). 저장값은 IATA 코드뿐(개인정보 아님, 예전 저장본은 '모름'). 출국하는 날에는 `도착하면 이 순서예요`(짧은 공항 카드), 도착 단계에는 그 공항 순서. 체크리스트 '도착하면'에 `도착 공항 순서 보기`(팩에 공항이 있을 때만 — 나라 화면 공항 묶음으로 바로 내려간다).

> "여권 만료 기간 확인부터 시작해서 전체 여행 과정에서 챙겨야 하는 사소한 것들까지 Check List로 Check해서 빠지지 않도록 관리할 수 있도록 해 주고, 같은 나라라도 여러번 갈 수 있으니 일정에 따라 서로 다른 여행이라고 판단하고 새로운 Check List를 관리할 수 있도록 해줘."

- **내 여행 목록** (내 여행 › 여행 목록 보기, 홈 여행 카드 `여행 n개 모두 보기`): 여행 중 → 다가오는 여행 → 지난 여행(접어 둠). 줄마다 나라 사진 원형 썸네일 + 나라 + 날짜 + 상태(출발까지 n일·여행 중·다녀왔어요) + `체크리스트 12 / 30` 막대. 날짜가 겹치는 여행은 막지 않고 맨 위 한 줄 + 그 줄에 `날짜가 겹쳐요`. 주 버튼 `새 여행 만들기`(새 여행을 만들면 바로 그 체크리스트로).
- **나라 화면 `내 여행에 넣기`** = 그 나라 **새 여행**. 같은 나라로 가는 다가오는 여행이 이미 있으면 `새 여행으로 만들까요, 기존 여행을 열까요?`를 묻는다.
- **여행 체크리스트** (여행 하나): 나라 사진 머리(`12 / 30` + 막대 + 지금 단계) → 단계 카드 8장(떠나기 한 달 전쯤 · 일주일 전 · 3일 전 · 출발하는 날 · 도착하면 · 여행 중 · 돌아오기 전 · 돌아와서 — 여행 6단계 막대에 얹힘, 단계마다 언제까지 + `3 / 7` 막대) → 내가 넣은 항목 → 여행 고치기 · 이 여행 지우기.
  - 항목 종류: **앱이 확인** (여권 남은 기간·여권 넣어 두기·나라 안내 받아 두기·이 여행 입국 카드 제출·여권 정보 지우기 — `앱이 확인했어요`, 사람이 바꿀 수 있음) / **팩 사실** (비자·머무는 기간, 입국 카드와 내는 기간, 꼭 챙길 물건 규칙, 영사콜센터·현지 긴급 번호, 귀국 면세·검역, 나라별 문장 — 출처·확인일, 팩에 사실이 없는 나라에는 만들지 않음) / **챙기기 안내** (예약 다시 보기·데이터·오프라인 지도·숙소 주소 현지어·공항 일찍·여권 따로 두기·남은 현금 등 — 숫자 없는 안내) / **내 항목** (글자만, 고치기·지우기).
  - 기간이 정해진 입국 카드는 기간이 열리는 날까지 잠김(`11월 1일부터 할 수 있어요`), 열리면 `입국 카드 준비하기`로 바로. 출발 당일까지 안 냈으면 그때만 빨강(`오늘 꼭 내요`). 기간이 없는 입국 카드(미리 안 내도 되는 것)는 빨강·늦음을 붙이지 않는다. 그 밖의 늦은 항목은 부드러운 주의 태그(`지금 해 두세요`) — 떠나기 전·도착 단계만.
  - 한 일은 제목·태그만 남기고 설명을 접는다. 다 끝난 지난 단계와 먼 뒤 단계는 머리·진행만 보이고 그 자리에서 펼친다(숨기지 않고 접기만).
  - 여권 남은 기간: 나라 팩 `requirements[].passport_validity`(공식 출처) 기준으로 지갑을 열 때 앱이 판단 — 괜찮으면 체크, 모자라면 `이 여행에는 여권 남은 기간이 입국일 기준 6개월 이상 필요해요. 지금 여권으로는 모자라요 — 여권 재발급을 먼저 알아보세요` + 외교부 여권 재발급 안내. 기준이 공식 안내에 없는 나라는 `나라별 기준을 공식 안내에서 확인하세요` + 외교부 해외안전여행. 여권이 없으면 손으로 체크하고 `여권 등록하기` 버튼.
- **내 여행 탭 '지금 챙길 것'**: 지금 단계까지 안 한 항목 3개(급함 → 늦음 → 지금 단계) + `체크리스트 전체 보기`. 입국 카드·여권 할 일이 없으면 이 카드가 지금 할 일(주 버튼).
- 체크 상태·내 항목·여행은 기기에만(백업 제외 DataStore). 알림은 새로 만들지 않았다(입국 카드 알림은 가장 먼저 떠나는 여행 하나에 맞춘다).

## 6. 입국 서류 자동 처리 흐름

1. 제출 가능일 알림: "태국 입국카드를 낼 수 있어요". (로컬 알림, WorkManager)
2. 3개 국어 확인 화면(5.2):
   - 서류에서 온 값 → **묶어서 1번 확인**
   - 추정값·선택값(목적 등) → **개별 선택**
   - 세관·건강 질문 → **그림 + 예/아니오로 직접 답변**
3. "맞아요, 입력해 주세요" → WebView에서 레시피대로 입력(5.3). 공식 사이트 위에 한글 말풍선 오버레이.
4. 사람 확인 지점(2.2)에서 멈추고 안내한다.
5. 사용자가 최종 제출 → 확인번호·QR·PDF를 기기 안(입국 때 보여 주기)에 저장, 홈 위젯 갱신.
6. 레시피 실행 실패(선택자 없음 등) → 즉시 수동 모드로 전환(화면 문구 '값 복사해서 넣기': 값 복사 버튼 + 공식 사이트) + 익명 실패 리포트 전송(9.4).

## 7. 개인정보·보안 설계 (필수)

### 7.1 원칙
- 여권·예약 서류·개인 프로필 등 개인정보(PII)는 **운영자 서버(Firebase 포함)로 절대 보내지 않는다**.
- PII가 기기 밖으로 나가는 유일한 경로: 사용자가 실행한 자동 입력으로 **허용 목록에 있는 정부 공식 도메인(HTTPS)**에 제출될 때.

### 7.2 문서 인식
- **여권**: ML Kit Text Recognition v2 **번들형**(모델을 앱에 포함)으로 MRZ 인식 → ICAO 9303 체크디지트 검증.
  - ML Kit은 이미지 등 입력 데이터를 기기 안에서 처리한다. 다만 API 성능·사용량 메트릭을 Google로 보내므로 개인정보 안내에 고지한다 `[재확인]`.
- **NFC 칩 검증(2차)**: JMRTD로 BAC/PACE 접속 → DG1 읽기 → SOD 전자서명 검증. **DG2(얼굴 사진)는 읽지 않는다**(생체정보 이슈 회피).
- **숙소·항공 서류**: 촬영 OCR + 규칙 기반 추출(날짜·예약번호 정규식). 가능하면 다른 앱의 '공유하기'로 PDF·텍스트를 받는 경로를 우선한다. 지원 기기에서는 기기 내 LLM(Gemini Nano, ML Kit GenAI) 보조를 선택적으로 쓴다. 실패 시 수동 확인.

### 7.3 저장
- Android Keystore 기반 AES-GCM 암호화 + 생체 인증 잠금.
- 원본 이미지는 값 추출 직후 삭제.
- 자동 백업 제외(`android:allowBackup`/`dataExtractionRules`), 민감 화면 `FLAG_SECURE`.
- 여행 종료 후 자동 파기 옵션(파기 전 설명 + 미루기).
- 여권 사본 보관은 사용자 선택(기본 끔), 암호화.

- **여권 남은 기간 (2026-10-02)**: 만료일은 지갑(Keystore AES-GCM)을 연 그 순간 메모리에서만 쓰고, 여행마다 **결과만**(`ok`/`short`/`unknown` + 기준 달 수·기준일 종류) 기기 안 여행 장부에 남긴다. 만료일·여권 번호는 새로 저장하지 않고 로그·알림·서버에 넣지 않는다. 체크리스트는 여권 값을 보이지 않으므로 FLAG_SECURE 화면이 아니다(여권 값을 보이는 화면은 그대로 FLAG_SECURE + 보안 배너).

### 7.4 권한·SDK
- 사진은 **Photo Picker**(저장소 권한 불필요). 카메라는 촬영 시에만.
- 교통 앱 설치 확인은 `QUERY_ALL_PACKAGES`를 쓰지 말고, 매니페스트 `<queries>`에 필요한 패키지만 선언한다.
- 분석·크래시 SDK가 입력 화면 내용이나 WebView 로그를 수집하지 않게 막는다. Analytics 이벤트에 여권·여행 일정 등 PII를 넣지 않는다. 광고 ID 수집을 끈다.
- 클립보드 복사 후 일정 시간 뒤 지우기 옵션.

### 7.5 레시피 보안
- 레시피는 **선언형 데이터(JSON)만** 허용한다. 원격으로 받은 JavaScript를 실행하지 않는다. (레시피 서버가 탈취되면 보관함을 읽어 외부로 보내는 경로가 생기기 때문)
- 모든 국가 팩과 레시피는 서명(Ed25519 권장)하고, 앱에 내장한 공개키로 검증한 뒤 적용한다.
- 레시피는 `official_url_patterns`에 일치하는 HTTPS 페이지에서만 실행한다.

### 7.6 신뢰 증명
- 문서 인식·보관함·입력기 핵심 모듈은 공개 저장소로 공개하는 것을 전제로 작성한다(12.6절 브랜치 보호와도 연결).

## 8. 정책·법률 요구사항

### 8.1 Google Play
- **오인 주장 정책**: 권한 없이 정부 서비스를 제공·중개하는 것처럼 보이면 안 된다.
  - 앱 이름·아이콘에 정부 연상 요소 금지. 입국 화면(나라 화면 › 입국·비자, 내 여행 › 여행 준비, 입국 카드 확인·자동 입력·값 복사해서 넣기)의 첫 항목과 스토어 설명에 "정부 기관과 제휴하지 않았습니다"를 고지한다. (예전 '입국 준비 탭 상단' — 탭 개편으로 위치를 옮김)
  - 정보 출처를 명시하고, 공식 사이트 화면을 그대로 보여주며, 사용자가 직접 제출한다.
- **접근성 API**: 공식 앱 조작용으로 쓰지 않는다. (자율 동작은 금지, 결정적 자동화도 고지·동의 필요 `[재확인]`)
- **데이터 보안 섹션**: 기기 안에서만 처리하는 데이터는 '수집'이 아니다. 다만 WebView로 정부 사이트에 제출되는 경로는 해석이 애매하므로 보수적으로 기재한다.
- **민감 정보**: 카메라·여권 처리에 대해 눈에 띄는 고지와 동의 화면을 둔다.
- **결제**: 수수료 링크는 앱 밖에서 쓰는 실물 상품·서비스라서 Play 결제 대상이 아니다.
- **타깃 API**: 최신 요구 수준을 확인하고 맞춘다 `[재확인]`.

### 8.2 한국 법
- **여권번호는 고유식별정보**다. 운영자 서버로 받지 않는 구조를 유지한다(받는 순간 별도 동의·암호화 의무 발생).
- **신고 책임은 신청자 본인**이다. OCR 오류가 입국 거부로 이어질 수 있으므로 원본 대조 화면이 필수다.
- **포지셔닝**: "대행"이 아니라 "본인 입력 보조 도구"로 표현한다. 무료 입국카드에 수수료를 받지 않는다.
- **수수료 링크(제휴 프로그램 링크)**: 표시광고법상 추천·보증 시 경제적 이해관계 표시 기준을 따른다(앱 표시는 '수수료 링크' 라벨 + 목록 맨 위 수수료 고지). 제휴 프로그램별 앱 게재 허용 여부와 표기 문구 규정을 확인한다 `[확인 필요]`.
- **보험·환전·카드**: 수수료를 받지 않는다. 보험 모집·금융상품 판매 중개 규제 대상이 될 수 있어, 법률 검토 전까지 공식 비교·안내 링크만 둔다.
- **가족 모드**: 동행자(미성년자 포함) 서류는 보호자 기기에만 저장하고, 등록 시 동의 확인 문구를 표시한다.

### 8.3 콘텐츠 저작권

- 데이터 `[재확인]`:
  - 인천국제공항공사 '항공사별 노선별 운송실적 정보조회' API: 매월 말일에 전월 기준 제공, 이용허락범위 제한 없음.
  - 한국공항공사 '전국공항 수송실적통계' API: 지방 공항 보완.
  - 네이버 데이터랩 검색어 트렌드: 실제 검색 횟수가 아닌 **상대 비율**만 제공. NAVER API HUB 종량제로 운영 중이므로 비용 확인 `[확인 필요]`.
  - 레디포트 찜 수(익명 집계): 이용자가 늘기 전까지 비중을 낮게.
- 초기 가중치: 여객 증감 50%, 검색 추이 30%, 찜 20%. 운영하며 조정.
- 필터: 비자 없이(입국 요건 데이터 재활용), 비행 시간, 이달에 좋은 곳, 가족 여행.
- ARIA가 주 1회 계산 → `rankings/latest.json` 배포. 오프라인 시 마지막 순위 표시. 기준 시점 항상 표시.
- 지금 상태: 공공 여객 통계 키(C3)·검색 추이 키(C4)가 없어 순위를 만들지 않는다(지어낸 순위 금지). 화면은 없고, 문구 15개(`rankings_*`)만 보존한다(운영자 결정 16번).

### 11.2 꼭 챙길 물건 + 구매 링크
- 꼭 챙길 물건 화면(5.10, 홈·내 여행 › 여행 준비에서 열기)의 체크리스트와 통합. '챙겼어요' → 준비 진행률 반영.
- 링크 원칙: 물건·여행 서비스만 수수료 링크(‘수수료 링크’ 표시 + 목록 상단 수수료 고지). 보험·환전·카드는 수수료 없이 공식 안내만.
- 추천 기준(목적지·계절·규정)으로 목록을 먼저 정하고, **수수료 때문에 순서를 바꾸지 않는다**.
- 가격은 저장하지 않는다. ARIA가 주 1회 끊긴 링크·품절을 점검해 교체 PR.

### 11.3 여행지별 한국인 인기 구매 상품
- 상품별 공식 통계가 없으므로: 관광청 쇼핑 안내·직접 조사로 후보 목록 → 네이버 검색 추이('도시 + 상품명') 상대 비교로 인기도 → 화면에 "한국인 검색 기준" 명시.
- 블로그·커뮤니티 수집 금지, 설명 직접 작성, 브랜드명·포장 사진 금지.
- 담은 목록은 ⑧ 귀국 단계에서 반입 가능 여부를 다시 확인. 면세 한도·반입 금지는 관세청·검역본부 공식 링크.
- 국가 팩에 포함되어 오프라인 동작.

### 11.4 여행사 소개 (2차)
- 목적지·유형별(패키지·자유여행·현지 투어) 목록, 선정 기준 공개, 수수료를 받는 여행사 링크에 '수수료 링크' 표시.
- 앱 안에서 예약·결제를 받지 않는다(여행업 등록 이슈). 외부 링크만.

## 부록 B. 이용 시나리오 (수용 테스트 기준으로 사용)

**A. 58세 부부, 첫 해외여행, 방콕 4박**
- D-45: 쉬운 모드, 방콕 찜 → Wi-Fi에서 팩 자동 저장
- D-20: 앱 준비 체크리스트로 Grab 설치·가입·카드 등록, 꼭 챙길 물건 확인
- D-3: 알림 → 3개 국어 확인에서 '관광'만 선택 → "맞아요" → 보안 문자·제출 → QR이 홈 위젯에
- 도착: 도착 모드 순서 카드, 입국심사에서 QR 제시
- 2일째: 인터넷이 끊겨도 '여기로 가기', 기사님께 보여주기 카드
- 귀국: 쇼핑 목록 반입 확인, 경비 정리, 여권 정보 파기 확인

**B. 중학생 자녀를 둔 4인 가족, 오사카 3박**
- 보호자 폰 가족 모드에 4명 등록, 일본 서류 한 번에 준비
- 자녀 폰은 자기 QR과 도움 탭만
- 지하철 타는 법 카드 + 지도 길찾기 연결
- 길을 잃으면 자녀가 '길을 잃었어요' 카드를 보여주고 보호자에게 전화

**C. 위기: 여권 분실**
- 도움 탭 → '여권을 잃어버렸어요' → 경찰 신고 → 대사관 연락 → 필요 서류 순서
- 사본 보관을 켜 둔 경우 암호화된 여권 정보 표시
