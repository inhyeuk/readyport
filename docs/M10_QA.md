## 접근성 (`A11yAuditTest`)
16개 화면(첫 실행·오늘 4단계·준비·꼭 챙길 물건·여행지·순위 설명·가이드·쇼핑·도움·지갑·보여주기·여행 만들기·이동하기)의 **누를 수 있는 모든 요소**(한 번에 94~124개)를 검사:
- 터치 영역 48dp 이상 — 통과
- TalkBack이 읽을 이름(글자 또는 설명) — 통과
- 보통 모드 / 쉬운 모드 / **쉬운 모드 + 글자 200%** — 모두 그려지고 통과
- 기존: 색 대비(`TokenContrastTest`, WCAG AA), 화면 제목 heading, 스와이프 없음, 쉬운 모드 '처음으로'·'소리로 듣기'

## 알려진 문제·남은 위험
- Visit Japan Web 서버는 앱 화면에도 HTTP 404를 돌려준다 → ARIA 구조 감시에서 제외(레시피 없음).
- TDAC 첫 화면에 Turnstile → ARIA 구조 감시는 늘 '수동 확인 필요'(우회하지 않음). TDAC·SGAC는 앱 셸만 보여 구조 해시가 셸 변화만 잡는다.
- Firestore가 nam5(미국)에 생성됨(C22).
- 태국 등 현지어 문장·쇼핑 이름 원어민 검수 전(C10·C16·C17).
- 출시 빌드 App Check(Play Integrity)는 Play 배포 전까지 실패한다 — 강제 모드를 켜기 전에는 영향 없음.
