## 수정 목록 (우선순위, 지적한 전문가)

### A. 공용 부품·일관성 (먼저, 한 작업자)
- **R1 누를 수 없는 칩이 버튼처럼 보임**(①②⑤): 홈 신뢰 칩, 플러그·전압 칩, 귀국 주제 칩, 준비물 칩 → 채움 없는 '정보 칩'(아이콘+글자, 테두리·채움 없음 또는 아주 옅은 Ground) 부품 하나로. 누를 수 있는 것과 시각적으로 확실히 구분.
- **R2 선택 표시 두 계열**(④): `SelectableCard`/선택 규칙 하나로 통합(00 첫 실행, 17 여행 고치기, 20 입국 카드, 24 도움 나라 칩). 스펙에 규칙 기록.
- **R3 라벨-값 행 다섯 벌**(④): `KeyValueRow`에 앞 아이콘·복사 버튼·마스킹 슬롯을 더해 20·21·26·30·32가 모두 쓰게.
- **R4 '급할 때는 도움' 행 두 벌 + ListRow 여백 16 고정**(④): 공용 부품 하나, 여백 토큰으로 카드 시작선 맞춤.
- **R5 반응형 판정이 36곳에 흩어짐, 쉬운 모드에서 내용 숨김**(④②): 판정을 Layout.kt 한 곳으로(fontScale 리터럴 제거). 내용은 숨기지 말고 배치만 바꾼다.
- **R6 긴급 번호가 하이픈에서 두 줄**(④): 실제 칸 폭을 재서 글자 크기를 단계적으로 줄이고(최소 기준 지킴), 큰 글자에서는 타일을 폭 전체로. 테스트에 '번호는 한 줄' 단언.
- **R7 긴급 타일 색 불일치**(①②⑤): 대표 1155 타일도 Help(주황) 계열로 통일. Navy는 보안·현지인에게 보여 주기·오프라인에만.
- **R8 불릿 기호**(③): 팩 문장 불릿은 뜻 없는 점 하나로 통일(✓는 앱이 확인한 상태에만, 금지 문장에 ✓ 금지). 05의 대시도 같은 점으로.
- **R9 출처 줄 정리**(③①④): 출처가 여러 개면 기관별로 묶어 한 줄씩, 날짜는 같으면 한 번. `확인`과 날짜 사이 줄바꿈 규칙 재확인(날짜만 넘어가지 않게).
- **R10 사진 동기 디코드**(④): 메인 스레드 디코드를 피함(painterResource 캐시/비동기, 크기 맞춤).
- **R11 아이콘 정리**(⑤③①): 같은 개념 한 아이콘(아이콘 맵 갱신), 먹거리별 아이콘 구분(과일·과자·차·커피·향신료 등 Material 아이콘으로 가능한 만큼), 버튼 앞 꺾쇠 제거, 경고 문장에 체크 금지.

### B. 화면 (A 뒤, 파일이 겹치지 않게 나눠서)
- **R12 비자 카드가 Accent 채움 정보 카드**(①⑤②): 03·04 비자 카드를 흰 카드(또는 은은한 그라데이션)로, Accent 채움은 주 버튼에만. 입국 카드 비용 '무료' 타일은 입국 카드(양식) 카드로 옮김 → 04에서 비자 비용 IDR 500,000 옆에 '무료'가 붙어 비자가 무료로 읽히는 문제 해결. 04: e-VOA와 All Indonesia 순서를 '1단계·2단계'로 표시. `IDR 500,000` 두 줄 쪼개짐 방지.
- **R13 홈 첫인상**(⑤②①): 히어로에 핵심 가치 한 줄(예: "입국 카드 칸은 앱이 채우고, 제출만 직접 눌러요") — 새 문자열, 모든 모드에서 보임. 02의 채움 버튼 3개 → 주 버튼 1개. 쉬운 모드 홈 길이 줄이기(히어로·여행 카드·나라·도움 우선, 나머지는 접거나 다음 화면 타일).
- **R14 귀국(15)·정리(16) 단계**(①③②): '여행이 끝났어요' 빈 카드 → 사진 머리 카드 + 한 줄 + '지금 할 일'. 귀국 전 확인은 접힌 요약(숫자 토큰 굵게). 출처 묶음(R9). 정리 단계에 축하감 있는 사진 카드.
- **R15 꼭 챙길 물건(19) 위계 반전**(①): 아직 안 챙긴 물건을 위·강조, 챙긴 물건은 아래로 낮게(초록 채움 제거, 체크 아이콘+흐린 글자).
- **R16 입국 카드 확인(20) 경고 세 겹·노랑 17회**(②③④): 맨 위 요약 1개('빈칸 N개' + 첫 빈칸으로 가기)만 남기고 행마다 '꼭 채워요' 반복 대신 작은 표시, 노랑은 실제 빈칸에만. '목록에서 골라 주세요'는 앱 칸이 아닌 사이트 칸 설명일 때만. 길이 줄이기(출처별 묶음 접기).
- **R17 05 안전·돈**(③): 여행경보 문장('가지 마세요' 포함)은 맨 위 위험 배너 슬롯으로 끌어올림(팩 문장 그대로, 지어내지 않음).
- **R18 쉬운 말·약속 충돌**(⑤②): 'MRZ'·'수동 모드' 같은 말을 쉬운 말로(새 문자열), '다른 폰으로 보내기'는 '이 휴대폰에만' 약속과 충돌하지 않게 문구·설명 조정(실제 동작 그대로 설명), 아직 없는 NFC 단계는 진행 표시에서 빼기. 날짜 입력은 숫자 자판, '도착했어요'는 되돌리기 제공, TalkBack '지우기'·'자세히 보기'에 무엇을 지우는지/펼치는지 붙이기.
- **R19 즐거움(delight)**(전원): 사진 재사용·어두운 태국 사진 → 히어로 스크림 조정/밝기 보정은 렌더에서(사진 파일 수정 없이), 나라 카드 칩 구성 통일, 첫 실행·정리 단계에 브랜드 순간. 과한 장식 금지.
- **R20 스토어 전용 픽스처**(⑤③): StoreAssetsTest 여권은 가짜 한국 이름(HONG GILDONG), 국적 KOR, 유효 만료일, 견본 QR, 오류 상태 없음. 스토어 순서: 홈 → 입국 카드 확인 → 나라 입국·비자 → 출국 단계 → 도움 → 내 정보(여권) → 이동하기 → (쉬운 모드) 여행 중. 영상 화면 제외. 캡션에 '정부 기관과 제휴하지 않은 앱이에요'.
