## 줄바꿈 (API 33 미만)
- `keepWords()`(HomeScreen.kt): API 33 미만에서만 어절 안 글자 사이에 WORD JOINER(U+2060)를 넣어 줄이 띄어쓰기에서만 바뀌게 한다(스펙 3.2의 `source_footer`·날짜와 같은 방법). API 33 이상은 테마의 `WordBreak.Phrase`가 맡으므로 글자를 그대로 돌려준다. 그래서 sdk 36 테스트가 찾는 문자열과 TalkBack 글자는 바뀌지 않는다.
- 묶음 A 화면이 직접 그리거나 부품에 넘기는 제목·본문과 홈 나라 출처 줄의 이름(`태/국`, `말레이시/아` 방지)에 적용했다. 전화번호에는 쓰지 않는다(스펙 3.2).

## 2단계·0단계 부품에 요청 (묶음 A는 부품 파일을 고치지 않았다)
1. `ChoiceCard`: 큰 글자 세로 배치(⑥).
2. `PhotoHeaderCard`: 제목 줄 아이콘은 `Alignment.Top`으로 두고 첫 줄 높이에 맞춘다(스펙 4.2). 맞추면 ⑧의 사진 머리 아이콘 빼기를 되돌릴 수 있다.
3. `StepList`: `detail`을 아이콘 열이 아니라 제목 글 시작선에 맞춘다(기본 모드도 해당). 1열·큰 글자에서는 단계 아이콘을 그리지 않는다.
4. `ReturnCheckCard(compact = true)`: 홈에서 가장 무거운 카드(기본 약 340dp)다. compact에서는 `shopping_return_body`를 빼거나 한 줄로 줄이고, `LinkRow`는 OpenInNew 아이콘을 글 끝에 붙여 라벨 칸을 넓힌다(200%에서 `면세 범/위`).
5. `CardNewsCard`(Navy)·`PhotoHeaderCard` 제목: 1열 200%에서 한 단계 작은 역할을 검토한다(지금은 `keepWords`로 어절 단위로만 꺾임).
6. `PhotoChip`: 가로 여백 10dp → 8dp를 검토한다(⑤의 같은 폭 칸 배치를 쓰면 필요 없다).
7. 갤러리(공유 파일): `TestPacks.homeUi()`에 `essentials = EssentialsSummary(5, 2)`를 넣어 진행 줄을 캡처한다. 그 전까지는 `HomeBundleCaptureTest`(build/gallery/bundle_a/)가 진행 줄과 하단 탭 변형(선택 상태 6가지, 쉬운 모드 2줄, sdk 31·200%, 320dp)을 찍는다.
8. 컨펌용 캡처: h6000/h12000dp 긴 창에서는 그림자 광원이 화면 맨 위라 아래쪽 카드 그림자가 겹친 카드처럼 보인다. 3단계 운영자 컨펌 자료는 기기 높이(851dp)로 스크롤 구간마다 찍거나 에뮬레이터·실기기에서 찍는다.
