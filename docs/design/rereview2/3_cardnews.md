## 총평

직전 라운드에서 지적한 "결론이 글에 묻힌 카드"가 상당 부분 정리됐다. 03·04·05 팩 불릿은 뜻 없는 점 하나로 통일됐다. 금지 문장 앞의 ✓도 사라졌다. 05에서는 3단계 여행경보가 맨 위 빨간 배너로 올라왔다. 04 비자 그리드는 `30일 | IDR 500,000` 두 칸으로 맞춰졌다. 15·16에는 사진 머리 카드와 숫자 타일이 들어가서, 여행 끝 장면이 처음으로 "카드뉴스의 마지막 장"처럼 보인다. 품목 아이콘(쿠키·찻잔·원두·잎·보석)과 1155 주황 타일, 20 입국 카드의 `빈칸 8개` 요약 카드도 의도대로 들어갔다.

남은 문제는 "규칙이 한 부품에만 적용되고 옆 화면에는 안 퍼진 것"이다. 숫자 굵게 강조는 귀국 전 확인 카드에만 있다. 05 돈, 03·04 들어갈 때, 19 보조배터리의 숫자는 여전히 문장 속에 있다. 빈칸 표시도 20은 `!` 아이콘, 21은 `꼭 채워요` 노랑 태그 7개로 서로 다르다. 귀국 전 확인 카드는 숫자를 굵게 했지만, 여전히 앱에서 가장 긴 글 블록(안내 2줄 + 4행 + 출처 3줄 + 링크 3행)이다. 이 블록이 홈·06·22·15 네 화면에 반복된다. 쉬운 모드와 200%의 여행 단계 표시는 아직 지름 5dp 점 6개이고, 그 상태로 스토어 08 이미지에까지 들어갔다. 다섯 항목 모두 목표선에 닿았지만, 남은 숫자 강조·태그 통일·반복 축소를 하면 clarity·consistency를 8점대로 올릴 수 있다.

## 남은 문제

1. **전역 — 숫자 강조 규칙이 귀국 카드에만 있음 (05 돈, 03·04 들어갈 때, 04 e-VOA 비용, 19 보조배터리, 22 판정 문장)** — 심각도 **중간**
   - 문제: 15·22·06의 귀국 카드는 `800달러`·`2L`을 굵게 강조한다. 그런데 바로 옆 카드의 팩 문장인 `20·50·100·500·1,000밧`, `미화 1만 5천 달러`, `IDR 1억 루피아`, `1인당 2개(160Wh 이하)`, 22 `면세 한도(미화 800달러)`는 모두 보통 글자다. 같은 "숫자 토큰" 규칙이 화면에 따라 적용되기도 하고 안 되기도 해서, 카드뉴스의 핵심 문법인 숫자 먼저 보기가 반쪽만 적용됐다. 200% 기본 05 `돈`에서는 숫자 목록이 6줄 문단 속에 묻힌다.
   - 고칠 것: 공용 `emphasizeNumbers()`를 `DotBullet`, `StatusTag`/`ImportVerdictBadge` 본문, `ExpandableDetail` 첫 문장, CheckRowCard 설명에 기본으로 적용한다. 값을 만들지 않고 스타일만 바꾸므로 정책 위조 위험은 없다. 단위 목록(밧·달러·루피아·Wh·개·일·L·ml·%·원)은 한 곳(`NumberTokens`)에서 관리하고, 테스트로 `05 돈` 노드에 굵은 span이 있는지 확인한다.

2. **06_country-shopping · 22_shopping · 15_today-return (+01·02 홈) — `귀국 전 확인` 블록 반복** — 심각도 **중간**
   - 문제: 숫자 강조로 읽기는 쉬워졌다. 하지만 카드 한 장이 안내 2줄 + 사실 4행 + 펼치기 + 출처 3줄 + 링크 3행으로 약 900px(393dp 기준 한 화면)이고, 06·22에서는 쇼핑 목록 바로 밑에 같은 크기로 붙는다. 면세 두 행은 둘 다 돼지저금통 아이콘이라 `기본 800달러`와 `술·담배·향수`가 아이콘으로 구분되지 않는다. 홈 기본 모드 길이는 운영자 결정 10번이라 감점하지 않았다.
   - 고칠 것: (a) 안내를 한 줄(`규정은 바뀔 수 있어요`)로 줄인다. 링크 3행은 `공식 안내 3곳 열기` 펼치기 하나로 묶고, 펼치면 지금 링크 행 3개가 나오게 한다. (b) 둘째 행 아이콘을 `LocalBar`(또는 `Liquor`)로 바꿔 면세 기본/별도를 구분한다. (c) 06·22에서는 `compact` 형태(제목 + 첫 행 1개 + `귀국 전 확인 전체 보기`)로 접고, 사실 4행 전체는 15(귀국 단계)에서만 펼친 채 둔다. 출처 줄은 접힌 형태에서도 그대로 보인다(출처 규칙 유지). FactGrid화는 부록 A 팩 필드가 생긴 뒤에 한다.

3. **21_manual-mode — 20과 다른 빈칸 표시, 단계 머리 글자 eyebrow** — 심각도 **중간**
   - 문제: 20은 칸 안 `!` 아이콘 + 맨 위 `빈칸 N개` 요약으로 정리됐다. 그런데 형제 화면인 21은 `꼭 채워요` 노랑 태그가 7번 반복되고 맨 위 요약이 없다. 맨 위에도 띠가 네 겹 쌓인다(비제휴 → 보안 → 주 버튼 → 노랑 `직접 확인 필요`). 카드 머리 `1단계/2단계/3단계`는 작은 파란 글자라서, 앱의 다른 순서 표시(번호 원 배지)와 다르다.
   - 고칠 것: 20과 같은 `RequiredMark`(라벨 뒤 Caution `!` 16dp, TalkBack `꼭 채워요`)로 바꾸고, 맨 위에 20의 요약 카드를 재사용한다(`사이트에서 직접 적을 칸 9개`). 노랑 `직접 확인 필요` 띠는 공식 사이트 버튼 아래 한 줄 InfoChip(`TouchApp` + 문구)으로 낮춘다. 단계 머리는 `StepList`와 같은 번호 원 배지 + 제목으로 통일한다(04의 `1단계 · 온라인 입국 신고` eyebrow도 같이).

4. **14·15 쉬운 모드 / 스토어 08 — 여행 단계가 5dp 점 6개** — 심각도 **중간**
   - 문제: 쉬운 모드에서는 JourneyStepper가 `지금: 여행 중 (6단계 중 4단계)` 글 + 현재 아이콘 원 하나 + 지름 약 5dp 점 6개로 바뀐다. 점은 쉬운 모드 사용자에게 너무 작아서 진행 그림 역할을 못 하고, 이 상태가 스토어 08 이미지(`글자와 버튼을 크게, 쉬운 모드`)에 그대로 실렸다. 200% 쉬운 모드에서는 글이 두 줄로 커지는데 점은 그대로라 대비가 더 커진다. `IconBadge`도 dp 고정이라 200% 쉬운 모드에서 32dp 제목 옆에 작은 아이콘으로 남는다.
   - 고칠 것: 점 줄을 폭 전체 6칸 세그먼트 막대(높이 8dp, 칸 사이 4dp, 지난 칸 Accent·현재 칸 Accent 테두리 + AccentSoft·남은 칸 LineSoft)로 바꾸고, 막대 위에 현재 단계 아이콘 배지(56dp)와 `여행 중 · 4/6`을 둔다. `IconBadge` 크기는 `LayoutInfo.textScale` 구간 토큰(≤1.15: 40/24dp, ≤1.5: 48/28dp, 그 이상·쉬운 모드: 56/32dp)으로 정한다. 스토어 08은 바꾼 뒤 다시 캡처한다.

5. **03_country-entry-TH (+04, 10, 18) — 같은 사실 반복, 내 날짜를 안 씀** — 심각도 **중간**
   - 문제: `90일`이 큰 타일, 바로 아래 요약 문장, `들어갈 때` 첫 불릿에서 세 번 나온다. TDAC 기간도 양식 카드 `내는 때`와 `들어갈 때` 둘째 불릿에서 같은 문장이 두 번 나온다. 그리고 여행 날짜(11월 3일)를 아는 10·18·03에서 `예: 5월 4일 도착이면 5월 2일~4일`이라는 일반 예시를 보여 준다. 사용자가 날짜를 직접 다시 계산해야 한다.
   - 고칠 것: (a) `FactGrid`에 기간 타일이 있으면 요약 문장(`summaryKo`)은 `자세히 보기` 안으로 넣는다. 양식 카드에 기간이 있으면 `들어갈 때`에서 같은 문장을 빼는 일은 팩 lint의 "요약·양식과 같은 문장" 경고로 잡는다(앱이 문장을 지우지 않음). (b) 여행이 있으면 `window_days_including_arrival`(팩 값)과 여행 도착일로 앱이 계산해 `내 여행: 11월 1일~3일에 내요`를 보여 주고, 예시 문장은 `자세히 보기`로 옮긴다. 10 머리도 `D-3` stat + `11월 3일 (화) 출발` 줄로 바꾼다(홈 카운트다운 카드와 같은 문법).

6. **docs/play/store — 스토어 이미지 8장과 그래픽 이미지의 카드뉴스 완성도** — 심각도 **중간 (delight·brand)**
   - 문제: 8장 모두 같은 남색 바탕 + 흰 두 줄 캡션 + 같은 비제휴 한 줄 + 화면 캡처라서, 넘겨 볼 때 리듬이 없다. 앱에서 가장 강한 카드뉴스 장면인 `90일` 타일, `1155` 주황 타일, 반입 판정 배지는 캡처 안에서 작게만 보인다. 02는 첫 화면 위쪽 1/3이 비제휴 띠·보안 띠·`현지어 크게` 버튼이라, 이 화면의 핵심 가치인 "앱이 채운 칸"이 아래로 밀린다. 그래픽 이미지 문구(`입국 서류, 한국어로 확인하고 공식 사이트 입력은 쉽게`, `…민간 앱입니다`)는 앱 안 가치 문장(`입국 카드 칸은 앱이 채우고, 제출만 직접 눌러요`)과 메시지가 다르고, 말투도 합니다체와 해요체로 섞여 있다. 업로드 여부는 운영자 결정 1번이라 감점하지 않았다. 여기서는 내용만 봤다.
   - 고칠 것: 캡션 위나 캡처 옆에 화면마다 핵심 숫자 하나를 큰 흰 글자로 올리는 "콜아웃"을 둔다(01 `5개 나라`, 02 `여권에서 6칸 · 항공권에서 6칸`, 03 `90일`, 05 `1155`). 캡처는 같은 화면을 그대로 쓰되, 콜아웃 숫자는 캡처 안의 값과 같아야 한다. 02 스토어 픽스처는 화면을 `서류에서 가져온 값` 카드부터 보이게 스크롤해서 찍는다(띠는 캡처 위 캡션의 비제휴 문구가 대신한다). 그래픽 이미지 문구는 앱 가치 문장과 같게 하고 말투는 해요체(`정부 기관과 제휴하지 않은 앱이에요`)로 맞춘다. 바탕은 사진 위 스크림 2장 + 남색 6장처럼 두 가지로 리듬을 준다.

7. **03_country-entry-TH — 히어로 `최종 확인` 날짜와 카드 날짜 불일치** — 심각도 **낮음 (신뢰)**
   - 문제: 히어로는 `최종 확인 2026.09.28`인데, 같은 화면 `들어갈 때` 카드 출처는 `최종 확인 2026.10.01`(TDAC 문장 재서명분)이다. 히어로 날짜가 화면 안 어떤 카드보다 오래된 값이라, 꼼꼼한 사용자는 "어느 날짜가 맞나"를 묻게 된다.
   - 고칠 것: 히어로 칩은 그 나라 팩 출처 중 가장 최근 날짜를 보이거나, 문구를 `가장 오래된 확인 2026.09.28`처럼 기준을 밝힌다. 어느 쪽이든 앱이 팩의 `last_verified` 값에서 계산하고 하드코딩하지 않는다.

8. **05_country-travel — `돈` 카드와 여행경보 레벨, `안전` 제목 두 번** — 심각도 **낮음**
   - 문제: 위쪽 빨간 배너 제목과 아래 카드 제목이 같은 `안전 (외교부 여행경보)`인데, 배너는 빨강이고 카드 배지는 노랑이라 색 뜻이 갈린다. 1·2·3단계는 아직 글 불릿이다. `돈`은 1번(숫자 강조) 말고는 구조가 그대로다.
   - 고칠 것: 아래 카드 제목을 `여행경보 단계`로 바꾸고 배지 톤은 Danger 계열로 맞춘다(위 배너와 같은 주제). 부록 A의 `advisory_levels`·`currency` 필드가 생기면 레벨 배지 행(1 노랑·2 주황·3 빨강)과 `StatTile(THB 밧)` + 지폐 InfoChip 줄로 바꾼다.

9. **04_country-entry-ID-visa — 단계 eyebrow 색과 값 크기** — 심각도 **낮음**
   - 문제: `1단계 · 온라인 입국 신고`는 파란 eyebrow + 파란 배지인데, `2단계 · 비자 온라인 신청`은 초록 eyebrow + 초록 배지다. 초록은 이 앱에서 "가능·완료" 뜻이라 2단계가 이미 끝난 것처럼 읽힌다. 같은 그리드의 `30일`(stat)과 `500,000`(FitText로 한 단계 작아짐)은 값 크기가 달라 두 타일 높이가 어긋나 보인다.
   - 고칠 것: 단계 eyebrow·배지는 둘 다 Accent로 통일하고 번호 원 배지(3번과 같은 부품)로 바꾼다. 같은 FactGrid 안에서는 FitText가 고른 가장 작은 스타일을 모든 타일에 적용한다(`FactGrid(uniformValueStyle = true)`).

10. **01_home / 02_home-with-trip / 18_prepare — `꼭 챙길 물건`** — 심각도 **낮음**
    - 문제: `플러그 · 전압 · 보조배터리`는 여전히 값 없는 주제 이름이다. 진행 `2 / 5`는 01(여행 없음)에는 있고 02(여행 있음)·18에는 없다. 정작 여행이 있을 때 진행을 안 보여 준다.
    - 고칠 것: 여행이 있으면 그 나라 팩 `power.*`로 `InfoChip(ElectricBolt, value = "220V")`·`InfoChip(Power, "한국 플러그 그대로")`를 보여 준다. 진행 `n/5` + 막대는 데이터가 있으면 01·02·18 모두에 같은 모양으로 둔다.

11. **27_settings · 28/29_wallet — SecurityBanner 본문 문단** — 심각도 **낮음**
    - 문제: `여권, 예약 서류, 같이 가는 사람 정보는…` 3줄 문단이 그대로다. 200% 쉬운 모드 30에서는 제목만 3줄이다.
    - 고칠 것: 제목은 그대로 두고, 본문은 InfoChip 약속 3개(`Lock 암호화 보관` · `CloudOff 인터넷으로 안 보내요` · `VisibilityOff 운영자도 못 봐요`)로 바꾼다. 문단 전체는 TalkBack 설명으로 남긴다.

12. **15_today-return — 담아 둔 물건 출처 5줄, 판정 요약 없음** — 심각도 **낮음**
    - 문제: 출처는 기관별로 묶였지만 여전히 회색 5줄이다(검역본부 2건, 관세청, 태국관광청 3건). 4개 품목이 위험 순(불가 → 주의 → 가능)으로 잘 정렬돼 있는데, 카드 머리에 그 결론이 없다.
    - 고칠 것: 카드 제목 아래 `StatusTag` 요약 줄 `반입 불가 1 · 주의 1 · 가능 2`(로컬 데이터)를 둔다. 출처는 기관 이름 줄만 먼저 보이고, 세부 문서명은 `출처 자세히`로 펼친다(기관 이름은 접힌 상태에서도 모두 보이므로 출처 규칙 유지).

13. **16_today-wrapup — 결산 타일** — 심각도 **낮음 (delight)**
    - 문제: `태국 / 다녀온 나라`는 숫자가 아닌 값을 stat 크기로 키운 것이라 결산 느낌이 약하다. 타일 바탕도 하나는 청록, 하나는 파랑으로 색 뜻 없이 다르다. 15에서 보여 준 `담아 둔 물건 4개`도 결산에서는 빠졌다.
    - 고칠 것: 나라는 사진 머리 제목(`태국 여행, 잘 다녀오셨어요`)이 이미 말하므로 타일에서 빼고, `4박 5일`·`담아 온 물건 4개`·(있으면) `기록한 지출 N건` 숫자 타일을 같은 AccentSoft 톤으로 둔다.

14. **용어 — 같은 `무료` 사실의 라벨이 화면마다 다름** — 심각도 **낮음**
    - 문제: 03·04 양식 카드는 `무료 입국 신고 비용`, 18 여행 준비는 `무료 입국 카드 비용`이다.
    - 고칠 것: 문자열 키 하나(`fact_label_form_fee`)로 통일한다. 화면 제목이 `입국 카드`이므로 `입국 카드 비용`을 권한다.

15. **27_settings (쉬운 모드 캡처) — 스위치 꺼짐** — 심각도 **낮음**
    - 문제: 직전 라운드와 같다. easy/27 캡처에서 `쉬운 모드` 스위치가 꺼짐으로 보인다.
    - 고칠 것: Gallery 픽스처 설정 상태를 모드와 맞춘다(컨펌 캡처 신뢰).

## 잘된 점

- 팩 불릿이 점 하나로 통일됐다. ✓는 앱이 확인한 상태(`챙겼어요`·`확인 완료`)에만 쓰여서, 체크 기호의 뜻이 앱 전체에서 하나가 됐다.
- 05 맨 위 Danger 배너(`3단계(출국권고)… 가지 마세요`), 22·15 반입 판정 배지의 위험 순 정렬, 1155 주황 타일 덕분에 위험한 정보가 가장 먼저, 가장 크게 보인다.
- 15 귀국(사진 머리 + `4박 5일 · 담아 둔 물건 4개` + 지금 할 일)과 16 정리(사진 + `잘 다녀오셨어요` + 숫자 타일)로 여행 6단계 이야기에 처음과 끝이 생겼다.
- 품목 아이콘 세분화(쿠키·찻잔·원두·잎·보석)와 Neutral 배지 통일로 쇼핑 목록이 아이콘만으로도 훑어진다.
- 20 입국 카드 확인의 `빈칸 8개` 요약 카드, 출처별 `6칸` 배지, 칸 안 `!` 표시는 노랑 남용을 끝낸 좋은 카드뉴스형 요약이다.
