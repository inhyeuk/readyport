# 나라 화면 길잡이 v3 — 메뉴와 내용 분리 (2026-10-02)

운영자 지적: *"메뉴 구조가 직관성이 떨어져. 입국심사/여행정보/쇼핑을 클릭했을 때 하단이 바뀌는 구조인데, 이 3개의 메뉴와 하단의 내용이 잘 구분되지 않아. 메뉴는 국가명 아래에 가로로 배치하고, 하단의 내용에도 메뉴가 배치된 구조여서 더 혼란스러워. 하단 메뉴는 모자이크 형태로."*

규칙은 `DESIGN_SPEC_2026-10-01.md` **부록 E**에 적었다(4.17·6-03·6-05·6-06·부록 C.2보다 우선).

## 무엇이 문제였나 (합의한 진단)

1. 섹션 전환(`ChoiceSegments`)이 내용 카드와 **같은 폭·같은 모서리·경계 없음**이라 카드 하나처럼 보였다.
2. `rememberGridColumns() == 2`일 때만 고정돼, 쉬운 모드·큰 글자에서는 **세로 라디오 목록**이 되어 스크롤과 함께 사라졌다 — 지금 어느 갈래인지 알 수 없었다.
3. 내용 안에 길 안내가 있었다: 여행 정보의 타일 넷(현지어와 긴급 번호 / 이동하기 / 여행 영상 / 오프라인 지도)이 **읽는 카드와 똑같은 흰 카드**로, 그것도 읽는 내용 **가운데**에 있었다.

## 바뀐 구조 (before → after)

```
[ before ]                               [ after ]
히어로                                    ┌ 머리 묶음 ─────────────┐
세그먼트(카드처럼 보임, 2열일 때만 고정)   │ 히어로                 │
안심 카드                                 │ 탭 줄(밑줄·흰 바탕·화면 │
비자 카드                                 │ 끝까지·언제나 고정)     │
입국 카드                                 └───────────────────────┘
들어갈 때                                 안심 카드 / 비자 / 입국 카드 / 들어갈 때   ← 읽는 것(흰 카드)
[보조 버튼: 이 나라로 여행 계획 만들기]    ─────────────────────────
                                          여기서 더 볼 수 있어요      ← 가는 길(연한 채움 모자이크)
여행 정보: 타일 2×2(흰 카드) ← 메뉴        [내 여행에 넣기        ]
          전기 / 돈 / 안전 / 지도          [현지어와 긴급 번호]
```

- **탭 줄 = 화면 틀**: 밑줄 선택 표시(Accent 2~3dp) + Accent 굵은 글자, 흰 바탕이 화면 **끝까지**(`fullBleed`), 아래 1dp 선 + 옅은 그림자. 내용은 그 아래로 지나간다. 모든 모드에서 가로 한 줄이고 언제나 고정이다.
- **모자이크 = 가는 길**: 연한 톤 채움(AccentSoft·HelpSoft·VioletSoft) + 첫 타일만 크게. 흰 읽는 카드와 **색과 크기로** 갈린다.
- 탭을 누르면 탭 줄이 맨 위에 서고 그 갈래 첫 카드가 바로 아래에서 시작한다(`scrollToKey(keys, "sections")`).

## 갈래마다 정한 것

| 갈래 | 읽는 것(그대로) | 가는 길(모자이크, 맨 끝) |
|---|---|---|
| 입국·비자 | 안심 카드, 비자, 입국 카드(채우기 버튼은 **카드 안**), 비자 신청(신청 버튼은 카드 안), 들어갈 때 | `내 여행에 넣기`(큰) + `현지어와 긴급 번호` |
| 여행 정보 | 여행경보 배너, 전기, 돈·안전, 지도 저장 | `현지어와 긴급 번호`(큰) + `이동하기` + `여행 영상` |
| 쇼핑 | 품목 미리보기 3개 + 반입 주의 배지 + `외 N개 더` + 출처, 귀국 전 확인 요약 | `쇼핑 리스트 보기`(큰) 한 장 |

- **`오프라인 지도` 타일은 없앴다**(프롬프트가 허용한 선택): 이 타일은 같은 화면의 지도 저장 카드로 스크롤하는 것이었는데, 모자이크가 그 카드 **아래**로 내려와 '같은 화면 안을 되돌아가는 길'이 됐다. `MapsCard`는 읽는 흐름에 그대로 있다.
- **쇼핑은 큰 타일 한 장**: 쇼핑 리스트 말고 이 갈래에서 갈 곳이 더 없다. 억지로 두 번째 목적지를 만들지 않았다(한 장이어도 연한 채움 + 머리 묶음이라 읽는 카드와 구분된다).
- **입국·비자의 둘째 타일 = 현지어와 긴급 번호**(`CountryActions.openHelp`, 이미 있는 길). 여권 정보는 나라 화면의 길이 아니라서 넣지 않았다.
- 카드 안에 남긴 버튼: `입국 카드 준비하기`(EntryFormCard), `비자 신청 시작`(VisaApplyCard) — 카드가 방금 설명한 일을 그 자리에서 한다. 메뉴가 아니다.
