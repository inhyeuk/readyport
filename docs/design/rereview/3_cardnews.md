```
expert: 카드뉴스·인포그래픽 에디터 (모바일 콘텐츠 디자인)
scores: visual=7.5 clarity=7.0 accessibility=7.5 consistency=7.0 delight=6.5
```

검토 범위: 기본 모드 타일 87장(tiles_v2 전부), 쉬운 모드(01·03·05·14·20·24·27·30), 200% 글꼴(기본 01·03·04·05·14·24, 쉬운 03·14·20·27·30). 1차 점수(5.5/6.0/7.5/6.0/4.0)와 비교했다.

## 총평

1차 때 "숫자가 문장에 묻혀 있다", "아이콘이 15개 남짓"이라고 지적한 부분은 크게 고쳐졌다. 03·04의 `90일 / 무료 / 30일 / IDR 500,000`, 05의 `220 V / 50 Hz`, 24의 `1155 / 191 / 1669`, 02의 `출발 3일 전`이 이제 큰 숫자 타일로 먼저 보이고, 여행 6단계 스테퍼·출국 순서 번호+아이콘·나라 사진 2열 타일·긴급 번호 카드도 카드뉴스 문법에 맞게 정리됐다. 하지만 **팩 문장을 그대로 붓는 카드(들어갈 때·돈·안전·귀국 전 확인)는 여전히 불릿 문단 덩어리**다. 그중 귀국 전 확인은 면세 800달러·술 2L·과태료 1,000만 원 같은 핵심 숫자를 문장 속에 둔 채 3개 화면에 통째로 반복된다. 같은 03 화면에서 입국 카드 내는 기간이 두 가지로 적혀 있어(도착일 포함 3일 vs 도착 3일 전부터) 결론을 먼저 보여 주는 디자인이 오히려 모순을 더 잘 보이게 만든다. 아이콘은 종류가 많아졌지만 쓰는 규칙이 흔들린다. 부정문 앞에 체크(✓)가 붙고, 불릿 기호가 체크·대시·아이콘으로 섞여 있고, 먹거리 6종이 모두 같은 포크·나이프 아이콘이며, 200%·쉬운 모드에서는 아이콘이 글자와 함께 커지지 않는다. 목표선(7.5)에는 visual·accessibility만 닿았고, clarity·consistency·delight는 아래 상위 5개를 고쳐야 넘는다.

## 남은 문제

1. **03_country-entry-TH (+18_prepare, 10_today-preparing)** — 심각도 **높음**
   - 문제: 같은 화면에서 입국 카드(TDAC) 내는 기간이 서로 다르다. 양식 카드는 `도착하는 날을 포함해 3일 안에… 5월 2일~4일`(3일), `들어갈 때` 둘째 불릿은 `도착 3일 전부터 도착하는 날까지`(4일)다. 스펙 D11이 경고한 모순이 디자인으로 더 눈에 띄게 됐다(양식 카드가 굵은 결론처럼 읽힘).
   - 고칠 것: 출시 전에 팩 원문을 운영자/ARIA가 하나로 맞추고(앱 하드코딩 금지), 팩 lint에 `window_days_including_arrival`과 불릿 문장 속 "N일 전부터"가 일치하는지 검사하는 규칙을 넣는다. 모순이 풀리기 전에는 컨펌 캡처를 올리지 않는다.

2. **03 / 04 `들어갈 때` 카드 (+05 돈·안전)** — 심각도 **높음**
   - 문제: 팩 불릿마다 중립 `Check`(✓)를 붙여서 `✓ 비자 없이 들어갈 수 없어요`(04), `✓ …입국이 거절될 수 있어요`(03)처럼 금지·경고 문장이 "됨/허용"으로 읽힌다. 05는 같은 종류의 팩 불릿을 대시(—)로 그려서 불릿 기호가 화면마다 다르다.
   - 고칠 것: 뜻을 모르는 팩 불릿에는 뜻이 없는 기호 하나만 쓴다. 6dp Accent 점이나 `Icons.Outlined.Circle` 8dp를 `IconBullet(neutral = true)`로 03·04·05·19 전부에 통일한다. ✓는 앱이 확인한 상태(챙겼어요·확인 완료)에만 남긴다.

3. **06_country-shopping · 15_today-return · 22_shopping — `귀국 전 확인`** — 심각도 **높음**
   - 문제: 가장 큰 남은 글 벽이다. 소개 3줄 + 돼지저금통 아이콘 문단 2개(800달러·30%·2L·400달러·200개비·100ml·만 19세) + 노랑·빨강 문단 2개(1,000만 원) + 출처 3줄 + 링크 행 3개로 이루어져 있고, 3개 화면에 그대로 반복된다(홈은 접힌 형태). 결론 숫자가 하나도 타일로 나오지 않는다.
   - 고칠 것: (a) 스키마를 바꾸지 않아도 되는 단계: 팩 문장 안의 `숫자+단위` 토큰(달러·L·개비·ml·%·만 원)을 `AnnotatedString`으로 굵게·Ink 강조한다. 값을 만들지 않고 스타일만 바꾸는 것이다. 소개 3줄은 `규정은 바뀔 수 있어요` 한 줄로 줄이고, 링크 3행은 `공식 안내 3곳 보기` 펼치기 하나로 묶는다. (b) 부록 A(팩 확장) 단계: `allowance_usd / alcohol_l / tobacco / perfume_ml / fine_krw` 구조 필드를 만들고 `FactGrid` 2×2 `800달러 · 술 2L · 담배 200개비 · 향수 100ml` + 금지 `Do/Don't` 카드(과일 ✕, 축산물 ✕ 과태료 최고 1,000만 원)로 바꾼다. 06·22에서는 compact로 접고, 펼친 전체 형태는 15(귀국 단계) 한 곳에만 둔다.

4. **05_country-travel — `안전 (외교부 여행경보)` · `돈`** — 심각도 **높음**
   - 문제: 가장 위험한 정보인 `3단계(출국권고)… 가지 마세요`가 대시 불릿 셋째 줄 4줄 문단 안에 있다. 여행경보 1·2·3단계는 색 배지로 보여 주기 가장 좋은 정보인데 글로만 있다. `돈` 카드도 밧·지폐 5종·1만 5천 달러 신고 기준을 모두 문장으로 늘어놓는다. 200%에서는 `20·50·100· / 500·1,000밧`처럼 숫자 목록이 줄 사이에서 끊긴다.
   - 고칠 것: 이번 릴리스에서는 섹션 카드 머리에 `NoticeBanner(Danger, GppMaybe)` 슬롯을 두고, 팩에 3단계 이상 지역이 있다는 사실(팩 문장에 `3단계` 또는 `출국권고` 토큰)이 있을 때만 `3단계 지역이 있어요 — 아래를 꼭 읽으세요` 고정 문구(앱 문자열, 값 없음)를 맨 위에 띄운다. 부록 A에서는 `advisory_levels[{level, regionKo}]`로 1노랑·2주황·3빨강 레벨 배지 행을 만들고, `currency{code, notes[]}`로 `StatTile(THB 밧)` + 지폐 `FactChip` 줄을 만든다.

5. **15_today-return** — 심각도 **중간**
   - 문제: (a) 담아 둔 물건 카드 아래 출처가 **6줄 + 날짜 1줄**짜리 회색 글 벽이다(태국관광청 3건, 검역본부 2건, 관세청 1건). (b) 맨 위 `여행이 끝났어요` 카드는 아이콘과 제목만 있는 빈 껍데기다(스펙 6장의 body `today_return_customs`가 빠짐).
   - 고칠 것: (a) `SourceList`에 같은 기관을 묶는 표시를 넣는다: `출처 농림축산검역본부(2) · 관세청 · 태국관광청(3) · 최종 확인 2026.09.29`, 기관 이름 줄을 누르면 세부 문서명을 펼친다. 모든 이름은 그대로 보이게 하므로 출처 규칙은 유지된다. (b) body를 되살리거나, 이 카드를 요약 숫자 카드로 바꾼다: `담은 물건 4개 · 반입 불가 1 · 주의 1`(로컬 데이터만 사용).

6. **20_form-confirm · 21_manual-mode** — 심각도 **중간**
   - 문제: 7타일이 넘는 긴 화면에 맨 위 요약 숫자가 없다(`빈칸 8개`는 중간 섹션 머리와 맨 아래에만 있음). `꼭 채워요` 노랑 태그가 8~10번 반복돼 노랑을 남용한다. 21은 카드 머리 단계 표시가 `1단계/2단계/3단계` 글자 eyebrow라서 다른 화면의 번호 원 배지와 다르고, 태그 위치(제목 옆/다음 줄)도 줄마다 다르다.
   - 고칠 것: 보안 배너 바로 아래에 진행 `StatTile` 2칸을 둔다: `자동으로 채움 12칸 ✓` / `직접 8칸 남음` + 진행 막대. 필드마다 붙는 태그는 라벨 뒤 `*`(Caution 색, `contentDescription = 꼭 채워요`) + 화면 위 범례 한 줄로 바꾼다. 21의 단계 머리는 `StepList`와 같은 번호 원 배지로 통일한다.

7. **전역 — 200%·쉬운 모드에서 아이콘과 숫자의 크기 비율** — 심각도 **중간**
   - 문제: 200%에서 `IconBadge`·`StatTile` 아이콘·`SectionHeader` 배지는 dp 고정이라 두 배가 된 글자 옆에서 점처럼 작아진다(05 `현지에서 쓰는 도구`, 30 `숙소` 카드, 24 `1155` 방패). 그래서 아이콘이 먼저 보이는 구조가 무너진다. 큰 숫자도 `30일`·`90일`이 카드 제목과 거의 같은 크기로 줄어 위계가 납작해진다. 200% 홈 출국 순서에서는 단계 아이콘이 빠진다. 쉬운 모드 14에서는 JourneyStepper가 글자 + 지름 약 5dp 점 6개가 되어 여행 단계 그림이 사라진다.
   - 고칠 것: 아이콘 배지 크기를 fontScale 구간 토큰으로 정한다(≤1.15: 40dp / ≤1.5: 48dp / 그 이상·쉬운 모드: 56dp, 안 아이콘 24→28→32dp). `stat` 역할은 titleLarge의 1.4배 이상을 유지하도록 상한 규칙을 바꾼다. 쉬운 모드 스테퍼는 점 대신 현재 단계 아이콘 배지(56dp)와 `6단계 중 4단계` 텍스트, 그리고 8dp 높이 6칸 막대로 그린다.

8. **06 · 15 · 22 — 품목 아이콘** — 심각도 **중간**
   - 문제: 선물용 과자·차·우메보시·두리안 칩·원두 커피·생망고가 모두 같은 포크·나이프 아이콘이어서 목록에서 아이콘이 구분 역할을 못 한다. 같은 품목의 배지 톤도 22는 주황(Help), 06·15는 회색이라 화면마다 다르다.
   - 고칠 것: `IconKeys.item()`을 분류 + 품목 ID 키워드로 세분한다: 커피·차 → `LocalCafe`/`EmojiFoodBeverage`, 과자·칩 → `Cookie`, 생과일 → `Eco`(또는 `Spa`), 소스·절임 → `SoupKitchen`, 공예품 → `Diamond`/`Redeem`. 반입 판정 색은 배지(`ImportVerdictBadge`)만 맡고, 품목 아이콘 배지는 모든 화면에서 Neutral 톤으로 통일한다.

9. **32_passport-confirm** — 심각도 **중간**
   - 문제: 위에는 빨간 `여권이 만료됐어요` 배너가 있는데, `만료일 2012-04-15` 행에는 초록 `확인 완료` 배지가 붙어 신호가 엇갈린다. 스테퍼에는 아직 없는 기능인 `칩 확인(선택)`이 단계로 들어 있고, 아래 `곧 추가돼요`에는 `(준비 중)`이 한 번 더 붙어 있다.
   - 고칠 것: 만료일 행만 `StatusTag(Danger, EventBusy, 만료됨)`으로 바꾼다(MRZ 대조 결과는 다른 행에 남김). NFC가 나오기 전까지 스테퍼는 `촬영 → 값 확인` 2단계로 그리고, ComingSoon 항목 글자에서 `(준비 중)`을 뺀다.

10. **01_home / 02_home-with-trip / 18_prepare — `꼭 챙길 물건`** — 심각도 **중간**
    - 문제: `플러그 / 전압 / 보조배터리` 칩은 값 없이 주제 이름만 있는데, AccentSoft로 채운 둥근 모양이라 눌러야 할 칩처럼 보인다. 진행 `2 / 5`는 01(여행 없음)에는 있지만 02(여행 있음)와 18 타일에는 없어서 같은 정보가 화면마다 다르게 나온다. 같은 주제의 아이콘도 백팩(01 사진 머리) / 체크리스트(18) / 여행가방(19)으로 세 가지다.
    - 고칠 것: 여행이 있으면 그 나라 팩 `power.*`로 `FactChip(ElectricBolt, 220V)`·`FactChip(Power, 한국 플러그 그대로)`를 보여 준다(출처 `SourceRef` 포함). 여행이 없으면 칩을 지우고 한 줄 설명으로 바꾼다. 진행 `n/5`는 데이터가 있을 때 01·02·18에서 모두 보이게 한다. 이 주제의 아이콘은 하나(`Luggage` 또는 `Checklist`)로 정한다.

11. **04_country-entry-ID-visa — 비자 FactGrid** — 심각도 **중간**
    - 문제: `IDR 500,000`이 `IDR` / `500,000` 두 줄로 꺾여 옆 `30일` 타일과 높이·기준선이 어긋난다. 셋째 타일 `무료(입국 카드 비용)`는 혼자 폭 전체로 늘어나, 덜 중요한 정보가 가장 큰 면적을 차지한다.
    - 고칠 것: 통화 코드는 값 위 eyebrow(`IDR · 루피아`)로 올리고 값은 `500,000` 한 줄로 쓴다. 홀수 번째 타일은 늘리지 않고 반 칸 그대로 두거나, 입국 카드 비용은 All Indonesia 양식 카드의 `FactChip`으로 옮겨 비자 그리드를 2칸으로 맞춘다.

12. **03_country-entry-TH — 같은 사실이 세 번** — 심각도 **중간**
    - 문제: `90일`이 큰 숫자 타일, 바로 아래 요약 문장(`…90일까지 머물 수 있어요(두 나라 협정)`), `들어갈 때` 첫 불릿에서 세 번 나온다. "한 사실은 한 번만"이라는 카드뉴스 원칙을 어기고 스크롤만 늘린다.
    - 고칠 것: `FactGrid`에 기간 타일이 있으면 `req.summaryKo`는 `자세히 보기` 안으로 넣는다(근거 한 줄로 `두 나라 협정` 같은 짧은 출처성 문구만 남기는 것은 팩 문장 수정 사항). 팩 불릿 중복은 팩 lint의 "요약과 같은 문장" 경고로 잡는다.

13. **10_today-preparing** — 심각도 **낮음**
    - 문제: 홈은 `출발 3일 전`을 큰 숫자 카드로 보여 주는데, 정작 `내 여행` 화면에서는 `출발까지 3일`이 회색 부제다. 입국 카드 기간도 내 여행 날짜(11월 3일)를 알면서 `예: 5월 4일 도착이면` 같은 일반 예시를 보여 준다.
    - 고칠 것: Today 머리를 `D-3` stat + 날짜 줄로 바꾼다. 1번(팩 모순)이 해결되면 `내 여행: 11월 1일~3일에 내요`처럼 내 날짜로 바꿔 보여 준다(앱 계산, 팩 값 사용).

14. **27_settings · 28/29/30_wallet — SecurityBanner 본문** — 심각도 **낮음**
    - 문제: `여권, 예약 서류, 같이 가는 사람 정보는…` 3줄 문단이 200% 쉬운 모드에서는 7줄이 된다. 27 `출처와 알림`·`개인정보 안내`도 4줄 문단이다.
    - 고칠 것: 제목(`내 정보는 이 휴대폰에만 저장돼요`)은 그대로 두고, 본문은 아이콘 약속 3개로 바꾼다: `Lock 암호화 보관` · `CloudOff 인터넷으로 안 보내요` · `VisibilityOff 운영자도 못 봐요`. 문단 전체는 TalkBack용 `contentDescription`으로 남긴다.

15. **24_help — 대표 긴급 번호 색** — 심각도 **낮음**
    - 문제: 대표 번호 `1155`는 Navy 카드인데 아래 긴급 번호 그리드는 주황(Help)이다. 원칙 4에서 Navy는 보안·보여 주기, 주황은 긴급이므로 같은 종류의 정보가 두 가지 색 뜻을 갖는다.
    - 고칠 것: 대표 타일은 Help 채움(진한 주황 + onDark 내용 세트)으로 바꿔 "긴급 = 주황"을 지키고, 크기·위치로 강조한다.

16. **16_today-wrapup** — 심각도 **낮음 (delight)**
    - 문제: 여행이 끝나는 순간인데 `정리 끝!` 글과 버튼만 있다. 카드뉴스 앱이 가장 기억에 남길 만한 장면을 비워 두었다.
    - 고칠 것: 로컬 데이터만으로 결산 카드를 만든다: 나라 사진 원형 + `태국 4박 5일` + `기록한 지출 N건` + `담아 온 물건 4개` stat 3칸.

17. **07_videos** — 심각도 **낮음**
    - 문제: `최신순` 아이콘(NewReleases)이 톱니 테두리 안 느낌표 모양이라 경고처럼 보인다.
    - 고칠 것: `Schedule` 또는 `Update`로 바꾼다.

18. **27_settings (쉬운 모드 캡처)** — 심각도 **낮음**
    - 문제: 쉬운 모드로 그린 캡처인데 `쉬운 모드` 스위치가 꺼짐으로 보인다. 픽스처 문제일 가능성이 크지만, 컨펌 캡처로 그대로 나가면 신뢰를 떨어뜨린다.
    - 고칠 것: Gallery 픽스처의 설정 상태를 모드와 맞추고, 실제 화면도 같은지 확인한다.
