## 총평

첫 검토에서 지적한 실제 위험(이름 없는 입력칸, 1.07:1 선택 표시, 48dp 고정, 확인 없는 삭제)은 거의 다 고쳤습니다. 쉬운 모드와 200% 글자에서 잘림, 겹침, 한 음절 줄바꿈이 보이지 않습니다. 1열 전환, 세그먼트의 세로 라디오 전환, 단계 표시의 글 변환(`지금: 여행 중 (6단계 중 4단계)`)은 시니어 기준으로 모범적입니다.
남은 문제는 마감보다 **정보 설계**에 있습니다. 같은 화면에서 TDAC 제출 시점이 서로 다르게 적혀 있고, 인도네시아 비자 카드에서 큰 녹색 `무료`가 `IDR 500,000` 옆에 있어 비자가 무료로 읽힙니다. 쉬운 모드 홈은 약 4,100dp(200%+쉬운 모드는 약 6,200dp)이고, 입국 카드 확인은 약 6,000dp입니다. 첫 화면에서 한 약속인 "한 화면에 할 일을 하나씩"과 맞지 않습니다.
누를 수 없는 칩(신뢰 칩, 플러그·전압 칩, 귀국 주제 칩)이 아직 버튼처럼 보입니다. `지우기`·`자세히 보기` 같은 일반 이름이 반복되어 TalkBack 탐색에서 문맥을 잃습니다. 이 둘은 D21과 원칙 8의 취지를 아직 다 채우지 못했습니다.
목표선(7.5)에는 accessibility·visual·consistency가 닿았고, clarity가 가장 낮습니다. 아래 1~3번은 컨펌 전에 처리하기를 권합니다.

2. **01_home / 02_home-with-trip (쉬운 모드·200%) · 높음 · 쉬운 모드 홈이 지나치게 김**
   - 문제: 높이가 약 4,100dp(200%와 쉬운 모드를 함께 쓰면 6,200dp)입니다. 나라 사진 카드 5장(1열), 출국 5단계, 준비물 카드, 귀국 전 확인(칩 3 + 펼침 + 출처 4줄 + 링크 3), 여권 카드, 도움 행이 차례로 쌓입니다. 첫 실행 화면이 약속한 "한 화면에 할 일을 하나씩"을 홈이 가장 먼저 어깁니다. 사진 1장이 약 220dp라 나라를 고르는 데만 두세 번 스크롤해야 합니다.
   - 고칠 것: 쉬운 모드 홈은 히어로 + (여행이 있으면) 카운트다운 카드 + 나라 목록 + `급할 때는 도움`만 둡니다. 나라 목록은 사진 높이를 120dp 안팎으로 줄이거나 원형 썸네일 가로 행으로 바꿉니다. 출국 순서·준비물·귀국 전 확인·여권 카드는 `여행 준비 기본 정보` IconTile 1개 뒤의 다음 화면으로 옮깁니다. 기본 모드도 귀국 전 확인을 홈에서는 `ListRow` 한 줄(아이콘 + 제목 + 셰브론)로 줄입니다.

4. **01_home(히어로·준비물 카드·귀국 전 확인), 쉬운 모드 히어로 · 중간 · 누를 수 없는데 버튼처럼 보임(D21 취지 미달)**

18. **갤러리 전역 · 낮음 · 확인하지 못한 부분**
    - 문제: 캡처에 하단 탭이 없어 쉬운 모드 2줄 라벨과 기본 모드 autoSize 하한(10sp)을 확인할 수 없습니다. 기본 모드 출처 글자는 13sp 회색이라 기본 모드를 고른 50대 사용자에게는 작습니다.
    - 고칠 것: 탭 바를 포함한 캡처를 추가하고, 출처 글자를 14sp로 올리는 것을 검토합니다.

## 잘된 점

- 쉬운 모드와 200%에서 잘림, 겹침, 한 음절 줄바꿈이 없습니다. 칸 폭 기준 1열 전환, 세그먼트의 세로 라디오 전환, 단계 표시의 `지금: 여행 중 (6단계 중 4단계)` 글 변환, 전화번호의 `-` 뒤 줄바꿈까지 큰 글자 대응이 꼼꼼합니다.
- 선택 표시는 Accent 채움 + 흰 글자 + 체크이고, 조작 요소 경계는 `LineStrong`입니다. 이전의 1.07:1 문제가 완전히 해결됐습니다.
- 파괴 동작에는 `DangerButton` + `DestructiveConfirm`(보안 화면은 FLAG_SECURE, 본문에 개인정보 없음, `남겨 두기` 취소)을 씁니다. 지우기 전 설명(`사진·영수증은 남고 여권 정보만`)도 분명합니다.
- TalkBack 이름 체계가 좋습니다: 복사 버튼 `성 (영문) 복사`, 긴급 타일 `전화 걸기 + 번호 + 메모`(다이얼만 열고 자동 발신 없음), 쇼핑 `%s 담기`, 나라 사진 타일 stateDescription, `곧 추가돼요` 항목 disabled.
- 신뢰 요소가 부품으로 강제됩니다: 입국 화면 첫 항목은 비제휴 + `마지막 제출은 직접 눌러요`, 보안 화면은 `내 정보는 이 휴대폰에만 저장돼요`, 정책 값에는 모두 출처와 최종 확인일이 붙습니다.
