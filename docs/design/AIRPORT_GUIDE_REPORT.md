# 공항에 도착하면 — 작업 기록 (2026-10-03)

운영자 요청(원문): "각 국가별 공항에서 입국 신고하는 위치를 안내해 줄 수 있으면, 정보를 추가해 주면 좋겠어"

브랜치 `claude/airport-guide`(main 0271e6d = 0.4.0 기준). 앱 버전은 올리지 않았다. 1차에서 태국 데이터와 화면·스키마를 만들고, 2차에서 나머지 8개 나라를 `merge_airports.py`로 합친 뒤 **출처 메모와 한 줄씩 맞춰 보며 교정**했다. 모든 팩 2026.10.03-1.

## 1. 사용자가 보는 것

| 화면 | 무엇이 바뀌었나 |
|---|---|
| 나라 › 입국·비자 | 입국 카드 카드 바로 다음 `공항에 도착하면` 카드: 공항 칩 → 공항 머리(이름, `방콕 · BKK · Suvarnabhumi Airport`) → 번호 단계(단계마다 아이콘·공식 위치 칩·짧은 설명) → 입국 카드 줄(노란 줄) → 자동 심사대 줄(✅/❌/물음표) + 공식 메모 → `공식 안내 페이지 열기` → 출처 |
| 여행 만들기·고치기 | `내리는 공항` 선택 카드(그 나라 팩 공항 + `아직 몰라요`). 공항 안내가 없는 나라는 칸이 없다 |
| 내 여행 › 출국하는 날 | `도착하면 이 순서예요`(짧은 공항 카드 — 단계 제목·위치·입국 카드 줄) + `공항 순서 자세히 보기` |
| 내 여행 › 도착 | 공항을 골랐으면 `도착했어요! 이 순서대로 해요`가 그 공항 순서(팩) → 유심·환전·숙소(앱 안내)로 번호가 이어진다 |
| 체크리스트 › 도착하면 | `도착 공항 순서 보기`(팩에 공항이 있을 때만) |

- **자동 심사대 줄 자리**: `egate` 단계가 있으면 그 단계 안, 없으면 입국 심사 단계 안. 조건이 있는 나라는 그 단계 제목이 조건을 먼저 말한다(대만 `자동 심사대(e-Gate)는 등록부터`, 베트남 `자동 심사대는 베트남 국민용`) — 판정 줄과 메모가 바로 그 아래 붙어서 조건을 놓칠 수 없다.
- **모름(null)인데 공식 안내끼리 다를 때**: `한국 여권으로 자동 출입국 심사대를 쓸 수 있는지는 공식 안내가 분명하지 않아요`(물음표) + 두 안내를 그대로 적은 메모. 판정도 메모도 없으면 줄이 아예 없다(일본·중국·태국).
- 링크 글은 `공식 안내 페이지 열기`로 바꿨다 — 실제 가리키는 곳이 안내도만이 아니라 공항 운영사·이민국의 도착 안내 페이지다.

## 3. 데이터 모양·검사

## 4. 교정한 것 (출처 메모와 한 줄씩 맞춤)

**지운 말 (메모가 받쳐 주지 않음)**
- 다낭: `여권에 입국 도장을 받으면 끝이에요`, `술·담배 등은 면세 한도가 있어요`, 도착 홀 `환전 카운터`, 큰 짐 종류(자전거·골프백·유모차) → 공항 안내에 없는 말.
- 노이바이: `도착 비자를 받는 사람은 … 도착 비자 절차를 먼저 해요` → 공항 안내에 없음.
- 발리: 세관 `인도네시아 관세청 사이트(beacukai.go.id)에서 볼 수 있어요`, 관광세 `lovebali.baliprov.go.id` 주소 → 그 페이지에 없는 안내·주소.
- 서우두: 도착 홀 `환전·안내 카운터`, 출처 없는 `도착 홀` 위치 칩.
- 후쿠오카: 검역 단계의 `국제선 2층 입국 검사장` 위치 칩(검역 위치는 공식 안내에 없다).
- 나리타: 세관 `짐을 기다리며 전자 신고를 했다면` → 짐 기다리는 동안 전자 신고는 하네다·후쿠오카·나하 안내다. 나리타는 `전자 신고를 했다면`으로 고치고, 그 말이 맞는 하네다·후쿠오카 세관 단계에 넣었다(출처 디지털청).
- 싱가포르: 자동 심사대 `홍채를 찍어요` → ICA 페이지에 없는 말(선글라스·모자·마스크 벗기만 적혀 있다).
- 세부: `mactancebuairport.com/airport-map` → 메모에 없는 주소. 실제로 연 국제선 도착 안내 페이지로 바꿨다.

**고친 말**
- 입국 카드 줄(`form_check_ko`)을 아홉 나라 모두 **"공항에서 어디서 보여 주나"** 한 가지로 통일했다. 비용·내는 기간을 되풀이하던 긴 문단(일본·싱가포르·말레이시아·대만·중국·필리핀·인도네시아)은 그 위 양식 카드가 이미 말하는 내용이라 뺐다. 덕분에 **대만의 숫자 모순**(양식 카드 `도착 7일 전부터` ↔ 공항 줄 `도착 3일 전부터`)도 사라졌다.
- 말레이시아 자동 심사대 메모 `도착 3일 전까지 MDAC를 냈고` → `MDAC를 미리 내야 해요`(MDAC는 도착 3일 전부터 내는 것이라 "전까지"는 틀린 말).
- 대만 메모를 `처음 쓰기 전에 반드시 직원이 있는 심사 카운터에서 등록해야 해요`로 시작하게 바꾸고, `자동 심사대(e-Gate)는 등록부터` 단계를 세 공항에 넣었다 — 조건이 메모 가운데 묻히지 않게.
- 인도네시아 메모에 공항 안내와 이민국 발표를 **둘 다** 적고 `어느 쪽인지 아직 정해지지 않았으니 현장 안내를 따라요`로 끝냈다(앱이 한쪽을 고르지 않는다). 판정이 null이면 메모가 보이지 않던 것도 고쳤다(`분명하지 않아요` 줄 추가).
- 베트남 메모에 `베트남 정부 전자신문의 2023년 8월 발표를 따랐어요. 그 뒤 바뀐 공식 안내는 찾지 못했어요.`를 넣어 2023년 근거를 현재 사실처럼 말하지 않게 했다(다낭만 공항 공식 안내).
- 노란 입국 카드 줄과 바로 아래 단계 설명이 **글자까지 같던 되풀이**를 나눴다(말레이시아 입국 심사, 발리 form_check, 필리핀 입국 심사·세관, CGK form_check).
- 출처가 보이지 않던 문장에 단계 출처를 달았다: 마닐라 입국 심사(이민국 eTravel), 마닐라 세관(관세청 여객 안내), 세부 검역(eTravel FAQ), 간사이 공동 키오스크(출입국재류관리청).
- 낱말 통일: 중국 팩 `입국카드` → `입국 카드`, `보여줘요` → `보여 줘요`.
- 단계 수·순서: 일본은 네 공항 모두 `공동 키오스크(VJW)` 단계를 갖게 했고(후쿠오카에 추가), 대만·베트남은 `egate` 단계를 넣었다. 모든 공항이 단계 3~7개, 번호 순서가 실제 걷는 순서다.

## 5. 베트남 사전 입국 정보(PAI) — 선택 양식으로

1차에서는 출처를 못 찾아 '들어갈 때' 섹션 문장으로만 안내했다(출처가 전자비자 사이트로 잘못 달려 있었다). 공식 출처가 생겨 **의무가 아닌 양식**으로 옮겼다.

- 팩 `forms[]`에 `VN_PAI`: `optional: true`, 공식 주소 `https://prearrival.immigration.gov.vn/`, 내는 때 `도착하기 3일 전부터 낼 수 있고, 도착한 뒤에 내도 돼요. 노이바이·떤선녓·다낭·깜라인·푸꾸옥 공항에서 쓸 수 있어요.`, 요금 `공식 안내에 요금이 적혀 있지 않아요`(요금을 밝힌 공식 문장이 없다), 출처 = 주싱가포르 베트남대사관 공지(2026-07-02).
- 스키마 `forms[].optional`(새 필드) + 앱: 양식 카드에 `꼭 내야 하는 건 아니에요` 알약(파랑 — 겁주지 않게), eyebrow `권장하는 사전 신고`, 보조 버튼 `미리 준비해 두기`, 설명 `의무는 아니지만 공식 안내가 내기를 권해요 … 앱이 칸을 대신 채워 주지는 않아요`.
- **자동 입력은 약속하지 않는다**: 레시피를 두지 않았고(확인 글자 창이 먼저 뜬다), `build_packs.check_optional_forms`가 optional 양식의 레시피·기간 일수를 막는다.
- **기한 있는 할 일로 만들지 않는다**: `CountryPack.requiredForms`(optional 제외)만 체크리스트 `입국 카드 내기`·오늘 단계·알림이 쓴다. 그래서 베트남 체크리스트는 한 줄 줄었다(26 → 25 + 공항 줄).
- 들어갈 때 섹션의 PAI 문장과 그 문장을 쓰던 나라 팩 체크리스트 항목 `prearrival`은 지웠다 — 한 사실을 한 곳에서만.
- 공항 줄도 같은 말로: `사전 입국 정보(PAI)를 냈다면 입국 심사 때 QR을 보여 줘요. 꼭 내야 하는 건 아니에요.` 떤선녓은 `사전 입국 정보(PAI) — 의무 아님` 단계로 QR 만들기까지 안내한다.
