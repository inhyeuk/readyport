# 나라 화면 길잡이 v4 — 그림 메뉴 (2026-10-02)

운영자 지적: *"나라별 메뉴 컨셉은 좋았어. 다만 그 메뉴가 디자인적으로 볼품이 없으니 세련되게 이미지화해서 구성해줘."*

v3 구조(메뉴와 내용 분리 · 메뉴는 언제나 닿는다 · 아래 내용이 바뀐다 · 맨 끝 모자이크)는 **그대로**, 메뉴 모양만 그림으로 바꿨다.
규칙은 `DESIGN_SPEC_2026-10-01.md` **부록 E.6**.

## 고른 것과 이유

- **그림 8장 직접 그림**(`components/Illustrations.kt`, 외부 자산 없음): 입국·비자 = 여권 + 입국 도장 + 작은 비행기, 여행 정보 = 접힌 지도 + 핀, 쇼핑 = 쇼핑백 + 금색 꼬리표, 모자이크용 말풍선·택시·재생 화면·여행 가방·체크리스트. 64 격자, 외곽선 2.4 둥근 선, 그림마다 진한 외곽선 + 주색 + 옅은 중간색 + 금색 포인트. 미리보기 HTML로 3번(구도·말풍선 꼬리·비행기 자리 → 쇼핑백 웃음 표시를 하트로·옆면 음영 → 고르지 않은 칸 색 처리) 고친 뒤 실제 캡처에서 다시 봤다.
- **선택 표시 = 떠오름 + 짙은 그라데이션 + 알약 막대 + Accent 굵은 글자.** AccentSoft 단색·Check(고르기 말)는 쓰지 않는다. 폭 전체 밑줄은 둥근 카드 아래에서 휘어 보여 가운데 알약으로 바꿨다.
- **고르지 않은 카드 = 파스텔.** 채도만 낮추면 주황이 흙빛(갈색)이 되어서, 채도 72% + 흰색 쪽 20%로 씻었다.
- **나라 색으로 물들이지 않았다.** 갈래 색(파랑·청록·주황)이 아래 모자이크 타일과 같은 뜻을 지니고, 나라 색은 바로 위 히어로 사진이 이미 맡는다. 사진에서 뽑은 색은 해 질 녘 사진(태국)에서 탁해지고 대비 검사를 흔든다.
- **두 메뉴는 한 번에 하나만**: 그림 메뉴가 접힌 줄 아래로 완전히 숨으면 접힌 줄이 180ms 페이드로 나타나고, 가려진 그림 메뉴는 TalkBack에서도 빠진다. stickyHeader 대신 목록 위 overlay(`AppScreen(overlay = …)`)라 높이가 바뀌는 고정 머리의 덜컹임이 없다.
- 갈래를 바꾸면 어느 메뉴에서 눌러도 새 갈래 첫 카드가 접힌 줄 **바로 아래**에서 시작한다(스크롤 뒤 실제 배치로 한 번 더 맞춤).
- 320×470 예산: 340dp 미만 창에서는 패널을 납작하게(2.4:1) 해서 정부 비제휴 고지가 스크롤 없이 보이는 자리(약 381dp)를 지켰다.
- 큰 글자: 393·360dp 글자 200%는 짧은 라벨(`입국/여행/쇼핑`)로 한 줄을 지킨다. 그래도 안 들어가는 좁은 칸(화면 분할 260dp + 쉬운 모드 + 200%)은 그림 카드를 폭 전체 행 셋으로 쌓는다.
