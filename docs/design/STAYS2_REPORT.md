## 1. 달력에서 날짜 고르기 (앱 전체)

### 무엇이 바뀌었나

예전에는 **모든 날짜를 숫자 자판으로만** 적었다(재검토 R18). 스펙 D20은 M3 `DatePickerDialog`를 쓰지 않기로 했었는데(달 목록 가로 스와이프·고정 40dp 칸·UTC 하루 밀림 걱정), **운영자가 달력을 요청해 그 결정을 뒤집었다**. 지금 Material 3 달력은 달을 가로로 스와이프하지 않고 `<` `>` 단추로 넘긴다.

**새 공용 부품 하나**: `app/src/main/java/com/readyport/ui/components/DatePick.kt`

- `DatePickField(label, value, onChange, …)` — 앱의 **모든** 날짜 입력이 이것 하나를 쓴다.
  - 칸은 기본이 **읽기 전용**이고, 칸을 누르거나 끝의 달력 단추를 누르면 Material 3 달력 대화상자가 열린다.
  - 칸 아래 **`숫자로 적기`** 단추(조용한 글자 단추)를 누르면 그 칸이 숫자 자판 칸이 된다 — 예전 길이 그대로 남아 있다(빠른 사람·TalkBack·200% 글자). 한 번 바꾸면 계속 숫자 칸이고, 달력 단추는 그대로 남아 언제든 달력으로 돌아간다.
  - 값이 올바르면 칸 아래 `11월 3일 (화)` 확인 글(`datePreview`), 저장 값은 예전과 같은 숫자 8자리(YYYYMMDD)다.
- 날짜 글자를 다루는 순수 함수(`dateDigits` · `parseDateDigits` · `digitsOf` · `DateDigitsTransformation`)도 여기 한 곳으로 모았다 — 예전에는 `ui/trip`과 `ui/wallet`에 **같은 함수가 두 벌** 있었다(커서 매핑이 미묘하게 달랐다).

### 어느 화면이 달력을 쓰나 (8개 칸, 전부)

| 화면 | 칸 | 달력이 여는 달 | 막는 날 |
|---|---|---|---|
| 여행 만들기·고치기 | 떠나는 날 · 돌아오는 날 | 적어 둔 값 → 떠나는 날 → 오늘 | 없음(어긋나면 띠로 알려 주고 저장 버튼이 막는다) |
| 숙소 넣기·고치기 | 체크인 · 체크아웃 | 적어 둔 값 → **이 여행 시작일** → 오늘 | 체크아웃은 **체크인 앞을 못 고른다**(있을 수 없는 날) |
| 예약 서류 가져오기(숙소) | 체크인 · 체크아웃 | 적어 둔 값 → 체크인 | 체크아웃은 체크인 앞을 못 고른다 |
| 여권 직접 입력 | 생년월일 · 만료일 | 생년월일은 마흔 해 전, 만료일은 올해 | 없음 |

- **해 범위**(달력에서 넘길 수 있는 해)로 길잡이만 한다: 여행 = 지난해~5년 뒤, 생년월일 = 1900~올해, 여권 만료일 = 10년 전~30년 뒤.
- 숙소 날짜 칸은 설명 줄에 **이 여행 날짜**를 적어 준다(`이 여행은 11월 3일 ~ 7일이에요.`). 여행 밖 날짜도 고를 수 있고, 고르면 예전처럼 `여행 날짜 밖의 숙소가 있어요` 알림이 뜬다 — 막지 않고 알려 주는 앱 습관 그대로.

### 접근성

- 달력 단추 이름: **`떠나는 날 달력에서 고르기, 지금 11월 3일 (화)`** (아직 안 골랐으면 `…, 아직 안 골랐어요`). 숫자 단추 이름: `떠나는 날 숫자로 적기`.
- 읽기 전용 칸에도 `onClick` 시맨틱(`달력에서 고르기`)을 달아 TalkBack에서 칸을 눌러 바로 달력을 연다.
- 두 단추 모두 쉬운 모드 56dp / 기본 48dp 터치(공용 `minTouchSize`).
- **대화상자는 접근성 점검(A11yAudit)이 띄우지 않는다**(갤러리 화면은 대화상자를 열어 두지 않는다). 그래서 달력은 `ui/components/DatePickTest.kt`가 따로 본다 — 열림/닫힘·고르기·숫자로 바꾸기·단추 이름·날짜 칸 크기. 측정값(`build/gallery/datepick/touch-*.txt`):
  - 기본 모드 날짜 칸 **보이는 48.0×48.0dp · 터치 48.0×48.0dp**
  - 쉬운 모드 날짜 칸 **보이는 28.0×48.0dp · 터치 48.0×48.0dp** — Material이 정한 격자라 쉬운 모드 56dp로 커지지 않는다(앱 토큰으로 못 바꾼다). 터치 영역은 48dp를 지키며, **쉬운 모드에도 `숫자로 적기` 길을 남겨 둔 이유**가 이것이다.
- 캡처: Robolectric이 대화상자 **창**은 찍지 못해(갤러리 캡처도 같다) 대화상자가 그리는 **같은 부품**(`DatePickCalendar`)을 흰 카드에 그대로 띄워 찍는다 — `build/gallery/datepick/00_field_closed.png`, `01_calendar.png`.

## 2. 숙소 좌표

### 화면 (숙소 넣기·고치기)

- `숙소 종류` 다음에 **접어 둔** `좌표` 묶음 하나. 머리 아래 한 줄: **`지도에서 정확한 자리를 찾을 때 써요.`** 대부분은 펼치지 않고 지나간다. 저장해 둔 좌표가 있으면 펼친 채로 연다.
- 펼치면 맨 위에 **`앱 안에는 지도가 없어요. 지도에서 고르고 싶으면 구글 지도에서 링크를 복사해 여기에 붙여 넣어 주세요.`** — 지도 SDK·API 키·네트워크 호출을 더하지 않았다는 사실을 화면에 그대로 적는다.
- 칸 하나(`위도·경도 또는 구글 지도 링크`)에 숫자든 링크든 붙여 넣는다. 읽어 낸 값은 바로 아래 **`이렇게 읽었어요 — 위도 13.7461 · 경도 100.5349`**, 못 읽으면 **`무슨 좌표인지 모르겠어요…`**(지어내지 않는다).
- `지도에서 좌표 확인`(읽어 낸 좌표만으로 구글 지도 열기) · `좌표 지우기` · `좌표를 넣어 두면 지도와 기사님께 보여 주기가 주소보다 좌표를 먼저 써요.`
- 못 읽는 글자가 남아 있으면 **저장 버튼을 막는다**(반쯤 적은 날짜와 같은 규칙) — 적어 둔 글자를 조용히 버리지 않는다.

### 받는 모양 (`stay/Coordinates.kt`, 순수 함수)

| 받는다 | 보기 |
|---|---|
| 숫자 두 개 | `13.75, 100.5` · `13.75 100.5` · `14, 100` · `-33.86, 151.2` |
| 방위 글자 | `13.75° N, 100.5° E` · `33.86S 70.66W` · `100.5E, 13.75N`(순서가 바뀌어도 가린다) |
| 구글 지도 주소 `@` | `…/maps/place/x/@13.7461,100.5349,17z/…` |
| 주소의 물음표 값 | `?q=` · `&query=` · `&destination=` · `&ll=` · `&center=` · `&sll=` · `&daddr=` |
| 구글 지도 긴 주소 | `…!3d13.7461!4d100.5349…` |

**안 받는다(모르겠다고 말한다)**: 숫자 하나 · 숫자 셋 이상(`13.7461, 100.5349, 15`) · 범위 밖(위도 ±90, 경도 ±180) · 도분초(`13°44'46"N`) · 주소 글자가 섞인 글(`123 Soi Fake 11, Bangkok`, `위도 13.7461 경도 100.5349`) · 좌표가 없는 짧은 링크(`maps.app.goo.gl/…`). 주소처럼 보이는 글에서는 **틀을 못 찾으면 더 뒤지지 않는다** — 주소 안 숫자를 좌표로 잘못 읽지 않게.

소수점 여섯 자리(약 11cm)로 반올림해 저장하고, 칸에 보이는 글자(`13.7461, 100.5349`)를 다시 읽으면 같은 값이 나온다. 테스트 `stay/CoordinatesTest.kt` 8개(쓰레기 입력 포함).

### 좌표가 있으면 좌표를 먼저

이미 그렇게 되어 있었고 테스트로 못 박았다(`StaysTest.coordinatesWinOverTheAddressText`): `Stays.searchQuery`(지도에서 보기)와 `RideLinker.mapsUrl`(길찾기·기사님께 보여 주기의 `Place`) 모두 좌표가 있으면 주소 글자 대신 `lat,lng`를 쓴다. 주소가 비어 있으면 '가는 곳'은 만들지 않는다 — 기사님께 **보여 줄 글자**가 없기 때문이다(좌표만으로는 보여 줄 게 없다).

## 3. 설정 › 내 정보의 묵는 곳 목록

- 자리: 내 정보(열림) — 여권 카드 → 예약 서류 → **묵는 곳** → 관리 줄 → 잠그기 → 여권 정보 지우기 → 곧 추가돼요.
- 머리 아래 한 줄: **`넣는 곳은 그 여행의 예약 단계예요. 여기서는 모두 모아 보고 고치거나 지워요.`** (부록 H 한 길 규칙 — 넣는 길은 하나, 나머지는 그리로 잇는다.)
- **여행별 묶음 카드**: 제목 `태국 · 11월 3일 ~ 7일`, eyebrow `숙소 2곳`. 줄마다 이름·날짜·종류·주소, 누르면 고치기(TalkBack `{이름} 고치기`), 아래 빨간 테두리 `지우기`(TalkBack `{이름} 지우기`, 확인 대화상자). 카드 맨 아래 `이 여행 열기` — 숙소를 넣는 자리로 가는 길.
- **`여행이 없는 숙소`** 묶음(맨 끝): 여행 id가 없거나 그 여행이 지워진 숙소. 본문이 왜 여기 있는지 말한다 — `예전 예약 서류에서 옮겨 온 숙소예요. 여행을 만들고 이 숙소 날짜를 맞추면 그 여행에서도 보여요.` **`STAYS_REPORT` 6.2의 "볼 화면이 없다"가 해결됐다.**
- 묶는 규칙(`Stays.group`, 순수 함수): 여행 id가 **같은 숙소만** 그 여행 묶음에 넣는다(한 숙소가 두 묶음에 들어가지 않게 — 여행 화면의 `forTrip`은 날짜로도 찾는다). 여행 날짜 빠른 순 → 여행 없는 묶음 맨 끝. 빈 묶음은 그리지 않는다.
- 고치기로 들어갈 때는 **여행 id 없이** 연다(`StayEditRoute(tripId = null)`) — 내 정보에서 고쳤다고 해서 숙소가 엉뚱한 여행에 붙지 않는다(그 숙소가 원래 붙어 있던 여행을 그대로 둔다).
- 개인정보: 내 정보 화면 그대로 — FLAG_SECURE, 맨 위 보안 띠, 암호화 보관함, 로그·서버로 나가는 값 없음. 보관함이 잠겨 있으면 목록은 비어 있다. 숙소를 지우면 '가는 곳'도 같이 지운다.

## 4. 숙소 종류: 사이트에 없으면 비워 둔다 (지금 동작 확인 + 설명 추가)

- **코드는 이미 그렇게 동작한다**: `FormValues.optionValue`는 그 레시피의 `stay_type` 선택지에 **없는 값이면 null**을 돌려주고 칸은 빈칸이 된다. `FormValues.suggest`도 선택지에 있을 때만 초안에 넣는다.
- **빈칸으로 센다**: `stay.type`은 MY_MDAC·TH_TDAC에서 `required: true`라 `missingRequired`가 센다 → 맨 위 빈칸 요약에 들어가고 `맞아요, 입력해 주세요` 버튼이 막힌다. 테스트로 못 박았다(`StayAutofillTest.typesTheSiteDoesNotOfferStayEmpty`).
- **확인 화면이 한국어로 설명한다**(새로 더함): 숙소 안내 카드가
  - 적어 둔 종류가 그 나라 선택지에 없을 때 → `적어 둔 숙소 종류가 이 나라 사이트 선택지에 없어서 비워 뒀어요. 잘못 고른 값이 그대로 제출되면 안 되니까요. 사이트에서 직접 골라 주세요.`
  - 아직 아무 종류도 안 골랐을 때 → `아직 안 고른 칸이라 빈칸으로 남아 있어요. 사이트에서 골라 주세요.`
  - 주소를 넣어 준 나라에서는 예전 `주소는 넣어 드리고, 지역은 사이트에서 골라 주세요` 카드 안에 이 줄이 함께 들어간다. 주소를 안 넣는 나라에서는 `숙소 종류는 사이트에서 골라 주세요` 카드가 따로 선다.
- 이유(운영자 결정 기록에도 적었다): **앱이 대신 고른 값은 사람 눈에 안 보이게 제출될 수 있다.** 게스트하우스를 `그 밖의 숙소`로 바꿔 넣으면 사람은 그걸 못 보고 제출한다. 비워 두면 반드시 사람이 본다.

## 6. 남은 것

1. **쉬운 모드 달력 날짜 칸 28dp(가로)**: Material 3이 정한 격자라 앱 토큰으로 못 키운다. 터치 영역은 48dp를 지키고 `숫자로 적기` 길이 있어 막히지는 않는다. 더 크게 만들려면 달력을 직접 그려야 한다(다음 단계로 둘지 운영자 확인).
2. **좌표 도분초(`13°44'46"N`)**: 지금은 모르겠다고 말한다. 받을지 확인 필요(구글 지도는 십진수로 복사된다).
3. **주소 없이 좌표만 있는 숙소**: 지도·길찾기는 되지만 `기사님께 보여 주기`는 보여 줄 글자가 없어 그리지 않는다. 좌표만으로 기사님께 보여 줄 모양(지도 캡처·QR 등)이 필요한지 확인 필요.
4. 실기기(S10 5G) 한 바퀴: 달력 대화상자 TalkBack·200% 글자·쉬운 모드.
