## 바뀐 것 (내부 기록)
- 근거: `docs/legal/U14_BOARD_REVIEW_2026-10-09.md`, 사장님 결정 `docs/design/attractions/DECISIONS_2026-10-09.md`(여권 생년월일·만 19세·여권 없으면 성인 가정).
- `board/BoardAge.kt`: 기기에 남는 값은 `adult`/`assumed`/`minor:YYYY-MM`뿐. 앱이 보관함 열림을 지켜보다 판정(ReadyPortApp).
- 쓰기 경로(가입·글·수정·댓글·댓글 수정·추천·신고·채택)는 저장소에서 막는다. 미성년이면 익명 계정도 만들지 않는다.
- 게시판 첫 화면: 미성년 = 안내 띠 + 쓰기 버튼 없음, 나이 모름(보관함 미열람) = `나이 확인하기`(기기 인증 → 보관함 열기).
- Firestore 규칙: 신고 이유 `minor` 허용. 색인: `reports.at` 컬렉션 그룹.
- 매월 purge-reports: 게시판 신고 중 신고 1년 경과 + 처리 끝난 것 삭제.
- 개인정보 처리방침 3절·3-2절·5절·6절·7절·7-1절·8절 개정.
