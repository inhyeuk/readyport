# Play Console 콘텐츠 등급(IARC) — 0.6.0에서 바뀌는 답

> 2026-10-09 작성. Play Console › 앱 콘텐츠 › 콘텐츠 등급 › `설문지 수정` → 바뀐 답만 고치고 다시 제출한다(새 등급 인증서가 즉시 나온다). **0.6.0을 출시 트랙에 올리기 전에** 한다 — 게시판이 든 버전을 낸 뒤 등급을 고치지 않으면 '사용자 상호작용' 미신고가 된다.

## 1. 지난번 답 (기록된 것만)

- 2026-09-29 제출: 결과 **전체이용가**, `온라인 콘텐츠` 관련 답 `예`(운영자 작업 메모 — 날짜·결과·그 한 가지만 남아 있다).
- **문항별 답(카테고리, 폭력·성·언어·약물·도박 문항 각각의 답)은 저장소·메모 어디에도 기록되지 않았다.** 콘솔의 `설문지 수정`을 열면 지난 답이 채워져 있으니 그대로 두고 아래만 바꾼다.
- 같은 날 다른 선언: 타깃 연령 13세 이상, 광고 없음, 광고 ID 미사용, 정부 앱 아님, 앱 액세스(로그인 정보) 필요 없음.

## 2. 바꾸는 답

설문 끝쪽 '기타/상호작용 요소(Miscellaneous)' 묶음 — 문구는 기억으로 옮긴 요지다 `[콘솔 문구 확인]`.

| 문항(요지) | 0.5.0 | 0.6.0 | 근거 |
|---|---|---|---|
| 사용자끼리 **글·이미지·음성으로 소통하거나 콘텐츠를 주고받을 수 있나요?** (users interact / exchange content) | 아니요 | **예** | 게시판 글·댓글·답글이 누구에게나 공개된다. 이미지는 지금 꺼져 있지만 글만으로 '예' |
| 사용자의 **현재 실제 위치**를 다른 사용자와 공유하나요? | 아니요 | 아니요 | 위치 권한 없음. 나라 태그는 이용자가 고르는 여행지 이름일 뿐, 사진 EXIF는 켜도 지운다 |
| 사용자가 **디지털 상품을 살 수 있나요?** | 아니요 | 아니요 | 인앱 결제 없음 |
| 앱 안에서 **사용자 개인정보를 제3자와 공유**하나요? (문항이 있으면) | 아니요 | 아니요 | 데이터 보안 2-6과 같은 판단 — 이용자가 직접 공개한 글은 제3자 제공이 아니다 |
| 웹 브라우저·검색 등 **제한 없는 인터넷 접근** (문항이 있으면) | 지난 답 그대로 | 그대로 | 게시판 검색은 앱 안 글만 찾는다. 링크는 자동으로 열리지 않는다 |

- 폭력·성·언어·약물·도박·공포 문항: **그대로**. 운영자 글·스크린숏에 해당 내용이 없다. 이용자 글의 욕설은 앱이 `＊`로 가려 올리고, 신고·운영자 가림이 있다 — IARC는 이용자 글 자체를 등급 문항으로 묻지 않고 '상호작용' 표시로 다룬다.
- **검토(moderation) 여부**를 묻는 칸이 나오면: 앱 안 신고(이유 6가지·3번이면 자동 접힘)·이용자 차단·운영자 가림(임시조치)·삭제·메일 연락이 있다고 답한다.

## 3. 예상 결과

- 연령 등급은 **전체이용가 그대로**일 것으로 본다 — IARC는 이용자 상호작용을 등급 올림 사유가 아니라 **상호작용 요소 표시**(`사용자 상호작용` / Users Interact)로 붙인다. 일부 지역 등급 기관은 표시 문구만 다르다 `[확인 — 제출 뒤 인증서의 지역별 등급표]`.
- 스토어 등록정보 등급 옆에 `사용자 상호작용` 표시가 생긴다.
- 등급이 예상과 다르게 올라가면(예: 12세) 타깃 연령 13세 이상 선언과 충돌하지 않으므로 그대로 두되, 결과를 이 문서에 적는다.

## 4. 함께 확인할 앱 콘텐츠 선언

- **사용자 제작 콘텐츠(UGC) 정책**: 별도 양식은 없고 심사에서 본다. 갖춘 것 — 첫 글 전 이용 규칙 동의, 글·댓글 신고(이유 6가지), 이용자 차단, 운영자 가림·삭제, 운영자 연락(게시판 아래 `운영자에게 알리기`), 개인정보 그물(여권 번호·MRZ·주민등록번호 막음). `docs/BOARD.md` 6절.
- **광고** 선언(지금 `광고 없음`): 공지의 `광고성 소식`(이벤트·혜택, 동의한 사람에게만)은 아직 한 번도 보내지 않았다. 레디포트 자신의 소식을 동의한 사람에게만 알리는 것이라 그대로 `없음`으로 두되, **처음 광고성 공지를 보내기 전에** Play의 광고 정의(자사 홍보 포함 여부)를 다시 보고 필요하면 `예`로 바꾼다 `[확인]`.
- **앱 액세스**: 게시판 쓰기는 앱이 익명 로그인을 자동으로 하므로 심사자에게 줄 아이디·비밀번호가 없다 → `모든 기능을 특별한 액세스 없이 이용 가능` 그대로.
- **타깃 연령**: 13세 이상 그대로. 만 14세 미만이 게시판에 쓰면 국내법상 법정대리인 동의 문제가 생길 수 있다(익명이지만 닉네임·글·ID가 저장된다) — 지금 앱에는 나이 확인이 없다. 법률 검토(C8) 때 함께 볼 것 `[법률 검토]`.
