# 디스콰이엇 (disquiet.io/products/readyport) 글 — 운영자가 직접 붙여 넣는다

승인 완료 2026-10-04. 앱 0.5.0(vc7) 기준.

---

## 1. 소개 (프로덕트 수정 → 소개)

> 지금 올라가 있는 글은 0.2.0 시절(4개 나라)이라 아래로 바꾼다.

```
해외여행 입국 서류와 여행 준비를 돕는 안드로이드 앱입니다. 1인 개발 중이고, 지금 구글 플레이 비공개 테스트 단계예요.

■ 여행 하나를 한 화면에서
여행을 만들면 계획 · 예약 · 서류 · 짐 · 출국 · 입국 · 여행 중 · 복귀 8단계로 지금 할 일을 차례로 알려 줍니다. 같은 나라라도 날짜가 다르면 다른 여행이고 체크리스트도 따로입니다. 못한 일이 남으면 하루 한 번 알려 줍니다(앱을 열지 않아도 됩니다).

■ 입국 서류 (9개 나라)
태국 · 일본 · 싱가포르 · 말레이시아 · 인도네시아 · 대만 · 중국 · 필리핀 · 베트남.
입국 카드 항목을 한국어 · 영어 · 현지어로 나란히 보여 주고, 앱 안 브라우저로 연 공식 사이트의 입력 칸을 채워 줍니다. 제출 버튼은 이용자가 직접 누릅니다. 사이트가 로그인이나 캡차를 요구하면 자동 입력 대신 '값 복사해서 넣기'로 안내합니다.

■ 공항에 도착하면
9개 나라 24개 공항의 도착 순서를 번호대로 보여 줍니다. 입국 신고서를 어디서 보여 주는지, 자동 출입국 심사대를 한국 여권으로 쓸 수 있는지까지. 공식 안내로 확인된 것만 쓰고, 분명하지 않으면 분명하지 않다고 그대로 적습니다.

■ 묵는 곳
한 여행에 숙소를 여러 곳 넣을 수 있습니다. 날짜별로 묵는 곳이 달라도 됩니다. 주소를 한 번 적어 두면 구글 지도로 바로 열고, 기사님께 보여 줄 현지어 주소로도 쓰고, 입국 카드 주소 칸도 채웁니다.

■ 개인정보
여권 정보는 휴대폰 안에만 암호화(Android Keystore AES-GCM)해 보관하고 서버로 보내지 않습니다. 여권 MRZ와 예약 확인서는 기기 안 OCR로 읽습니다. 여행 · 체크리스트 · 숙소도 이 휴대폰에만 저장됩니다.

■ 인터넷 없이도
저장해 둔 나라 안내, 현지어 문장 카드, 긴급 연락처, 입국 QR은 비행기 모드에서도 열립니다(서명된 국가 팩).

■ 만든 방식
Kotlin · Jetpack Compose, 광고 · 분석 SDK 없음, 무료. 국가 정보는 공식 출처만 쓰고 출처와 확인 날짜를 함께 보여 줍니다.

■ 테스터 모집 중 (안드로이드)
1) 그룹 가입: https://groups.google.com/g/readyport-testers
2) 테스트 참여: https://play.google.com/apps/testing/com.readyport
의견: inhyeuk@gmail.com

※ 레디포트는 정부 기관과 제휴하지 않은 민간 앱입니다.
```

## 2. 포스트 (프로덕트 페이지 → 포스트 → 글쓰기)

제목:

```
입국 카드 때문에 공항에서 헤매던 걸 앱으로 만들었습니다 (테스터 모집)
```

본문:

```
해외여행 갈 때마다 같은 걸 반복했습니다. 태국 TDAC가 뭔지 검색하고, 영어로 된 칸을 번역기로 돌려 가며 채우고, 공항에 내려서는 어디로 가야 하는지 몰라 두리번거리고요.

그래서 레디포트를 만들었습니다.

여행을 만들면 계획 · 예약 · 서류 · 짐 · 출국 · 입국 · 여행 중 · 복귀 8단계로 지금 할 일을 알려 줍니다. 입국 카드를 낼 수 있는 날이 되면 알려 주고, 공식 사이트를 앱 안에서 열어 칸을 채워 줍니다. 제출 버튼은 직접 누르셔야 합니다 — 정부 사이트에 대신 제출하는 일은 하지 않습니다.

지금 9개 나라(태국 · 일본 · 싱가포르 · 말레이시아 · 인도네시아 · 대만 · 중국 · 필리핀 · 베트남)를 다루고, 24개 공항의 도착 순서도 넣었습니다. 자동 출입국 심사대를 한국 여권으로 쓸 수 있는지는 공식 안내에 적힌 나라만 표시했습니다. 싱가포르는 됩니다. 대만은 되지만 첫 이용 전에 유인 카운터에서 등록해야 합니다. 이런 건 직접 겪기 전엔 모르더라고요.

만들면서 지킨 것 세 가지입니다.
· 공식 출처만 씁니다. 블로그에서 본 내용은 넣지 않았고, 모든 안내에 출처와 확인 날짜를 적었습니다. 공식 안내가 애매하면 애매하다고 그대로 씁니다.
· 여권 정보는 휴대폰 밖으로 나가지 않습니다. 서버가 없습니다.
· 광고와 분석 SDK가 없습니다. 무료입니다.

■ 테스터를 찾습니다 (안드로이드)
구글 플레이 정책상 정식 출시 전에 12명이 14일간 테스트해야 합니다. 설치만 해 두셔도 큰 도움이 됩니다.

1) 그룹 가입: https://groups.google.com/g/readyport-testers
2) 테스트 참여: https://play.google.com/apps/testing/com.readyport

써 보시고 이상한 점이 있으면 알려 주세요. 특히 실제로 입국 카드를 내 보신 분의 의견이 궁금합니다.

※ 레디포트는 정부 기관과 제휴하지 않은 민간 앱입니다.
```
