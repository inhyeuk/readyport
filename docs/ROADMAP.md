## 14. 사람이 해야 하는 일 (Claude Code는 목록화·안내만)

- Play Console 계정, 앱 서명 키, 스토어 등록, 타깃 API 확인
- Firebase 프로젝트 생성, 서비스 계정·토큰 발급, GitHub secrets 등록
- 공공데이터포털(외교부·인천공항·한국공항공사) 및 네이버 API HUB 키 발급, 비용 확인
- 제휴 프로그램 가입과 약관(앱 게재 허용, 표기 문구) 확인
- 법률 검토: 개인정보처리방침, 보험·금융 링크, 가족 모드 동의, 정부 서비스 관련 스토어 정책
- 상표 검색(KIPRIS), 스토어 동일 이름 확인
- 현지어 문장·양식 라벨의 원어민 검수, 긴급 연락처·대사관 정보 공식 출처 검수 (화면의 '원어민 검수 전' 배지는 2026-10-01 운영자 결정으로 뺐지만, 검수는 출시 전에 한다 — QUESTIONS C10·C16·C17)
- 실기기 테스트: NFC, 카메라, 원형·둥근 사각 런처, Android 13+ 테마 아이콘
- 실제 사용자 테스트: 60대 무경험자 5명, 중학생 5명에게 '입국카드 제출(제출 직전까지)'과 '숙소까지 이동' 과업 수행
